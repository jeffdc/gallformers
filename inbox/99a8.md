Background. 50ff's step 5 (process Sources into a copy of production, Jeff and Adam, on the preview server) lists "where the producer runs at scale (subscription, API account, or a server job)" among what to settle before scaling. Nothing more is written about it.

Today: `services/import-producer` (Python, `uv run produce …`) runs each phase as headless Claude Code (`claude -p`) logged in with Jeff's Claude subscription, from a local checkout. It removes `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN` from the child process so runs bill the subscription, not an API key; `run.json` records the API-equivalent cost (about $9 a Source). Claude Code's `--safe-mode` keeps user settings, hooks, skills and memory out of the runs; the README notes read-only shell commands can still slip through auto-approval, and full lockdown would mean replacing Bash with an MCP tool. Packages are delivered to Gallformers' private bucket and imported by Oban jobs.

The options named: keep the subscription; an API account (billed per token); or a server job. No consequences or recommendation are recorded.
