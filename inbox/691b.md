Context (f14c 'Other decisions', Jeff 2026-11-05: plants get authorship from WCVP, whose data Gallformers holds; built as Ranges.WcvpAuthorship, merge f035ecc0). Plant names are editorial, so WCVP's authors are written straight to taxon_names.authorship, audited, with no Fact. A plant name's WCVP record is the linked record when it bears the same name. Otherwise it is the records of the same name at the same rank: one record, or several giving the same authors. When they differ, the records in the synonymy of the plant's linked record are used.

Chosen: only plant names with a blank authorship are filled; an authorship a curator gave is never overwritten. A name with several WCVP records giving different authors, and nothing to choose between them, is ambiguous: it is left blank, and counted and listed in the run's summary for a curator. On a WCVP relink (follow_link/3), the accepted name's authorship is replaced only when it was the previous record's (WCVP's, not a curator's).

Why: a curator's authorship stands, since plant data is editorial and curators edit it freely. For an ambiguous name, filling in one record's authors would be a guess.

Alternative: WCVP's authorship overwrites all plant authorships, or an ambiguous name takes the first or most common record's authors.

Code: Ranges.WcvpAuthorship (backfill/2, follow_link/3), run by the catalog migration (step 11b), by mix gallformers.wcvp.authorship and by Release.backfill_wcvp_authorship/0; shown on plant pages, editable in plant Edit mode (HostLive.Editor).
