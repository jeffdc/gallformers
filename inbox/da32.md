Context (phase 2, f923): a Source's taxonomic statement (placement, accepted name, synonymy, rank, split, common name) competes by the Source's date, but counts only once a curator accepts it; until then it is recorded and 'awaiting'. Statements of the Gallformers Sources (Gallformers' own and the undated 'Gallformers legacy data', which holds today's tree at cutover) need no acceptance. A question is raised only for a statement newer than every counting statement in its slot. 
Chosen: a taxonomy batch from the Gallformers Source counts without acceptance and moves the tree as soon as it is applied, like any other Gallformers statement. Kept as the rare exception: Gallformers states taxonomy only for an undescribed Gall's Inducer or a position no paper supports.

Why: consistent with the rule that Gallformers' own statements need no acceptance (f923 Task 1: a taxon_* attribution counts if accepted, or if its Source is Gallformers or the legacy data).

Alternative: gate Gallformers taxonomy batches with acceptance too, so every tree change passes the taxonomy queue.

What it affects: Facts.counts?/3 and Facts.needs_acceptance?/2 (the gated kinds), Taxa.Sync. Under the unified edit model (d3b0) every curator edit becomes a package of the one Gallformers Source, so this rule decides that a curator's non-plant taxonomy change made as Gallformers' own position takes effect at once; edits credited to a paper via 'Based on which Source?' are accepted at once by design (f923 Task 8).
