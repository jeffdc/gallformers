Context (ec2c, Jeff's live-use findings 2026-11-06, item 2: 'Applying from the tray should leave Edit mode'): curators' edits collect in the change tray. Review and apply applies Fact items as one Gallformers package and editorial items directly; each item comes out applied, submitted (waiting for its package's outcome) or held with a reason.

Chosen: after Review and apply, the page leaves Edit mode when anything was applied or submitted. When every item is held (nothing went through), it stays in Edit mode, so the curator can fix what held them.

Why: Jeff asked for leaving Edit mode after applying. Leaving when nothing applied would drop the curator out of the mode they need in order to fix the held items.

Alternative: always leave Edit mode after Apply, or never (leave it to the curator).

Code: GallformersWeb.TrayLive (applied/2 pushes 'leave-edit' when result.applied or result.submitted is non-empty), the LeaveEdit JS hook (assets/js/hooks/leave_edit.js, drops ?edit); commit 3b242209.
