Context (phase 2, f923 Task 8 'Based on which Source?'): a non-plant tree edit in the taxonomy admin or on the species page is recorded as the chosen Source's statement. The Source can be an existing one, or a citation created on the spot (title, authors, date, optional DOI).

Chosen: creating that citation is logged as a Source edit. It runs in an audited transaction (Import.record_source_created/2 -> Import.SourceEdits.record_create/2 -> Sources.create_citation/2, operations 'import.record_source_created' and 'sources.create_citation'), shows in the change log as 'Added a Source', and is a :source_edit 'create' replay entry before the :taxonomic_statement it supports.

Why: the source table has no row-level audit (Carbonite doesn't track it; only source_documents and source_corrections are tracked), so the audit trail holds the transaction but no row change. The Source edit entry is what lets the creation be seen and replayed.

Alternative: track the source table with Carbonite (captured for after release as 'Audit the source table with Carbonite'), so every Source creation and edit has row history.

Code: Gallformers.Sources.create_citation/2, Import.SourceEdits, Audit.ChangeLog (wording), Import.Replay (:source_edit).
