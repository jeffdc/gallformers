Background: of the 524 notes on described Galls, code can write the patterned statements (157 'added (tentatively) as a host based on [observation]' as Host Facts; 109 'observed in <place> in <month>' as occurrence Facts). About 200 notes have taxonomy or ruling sentences (synonymy, 'described as', 'treated as'; 'however', 'suggests', 'may be') that need judgement. Pattern analysis (2026-11-05): 206 described notes have such a sentence (359 sentences); taxonomic remarks themselves stay text (Gallformers is a taxonomic authority only as a rare exception; the position comes through the paper it rests on, in the backscan).

Options:
- LLM in chunks: ~50-100 notes per run, one text block per note, each Gall declared by its Gallformers ID. Needs a contract change: today a note package (`source.note`, `Import.NotePackage`, `mix gallformers.import.notes`) quotes one note and one Gall. Each chunk costs about a paper (~$8-12, estimate); all 524 described ≈ $60-90, against $700-1,700 one note at a time (the 2026-10-30 trial: 10 notes, $12.83, about $1.28 a note). One Source per group fails: thousands of Facts overwhelm one session. Run one trial chunk (~50 notes, ~$6-10) first.
- Curator queue: no LLM cost; curators read each and decide. Rulings were already to be looked at case by case (Jeff, 2026-10-28: a ruling is a note taking a side in a conflict).
Under the conflict rule either way, a note Fact that would supersede or withdraw a Fact from the literature goes to a curator. Note the later edit model (d3b0, 2026-11-07) decided ID notes are 100% editorial and old notes become Gallformers changes with their own dates; item a6a3 reconciles the two, so the question may change shape.
