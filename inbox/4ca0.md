Background: in the edit model (Jeff, 2026-11-07) every Fact edit is the ingestion of a Gallformers statement through the one ingestion path, and all edits that can be inline are inline on the main pages with one shared set of components. Fact-bearing pages: the Gall page, every non-plant rank (species, genus, family, intermediate ranks, section), a Source's own page and the review's Facts. While designing the edit framework Jeff raised (as a question, not a wish) whether every Fact edit should begin and end in the Facts panel (`facts_view`, with each Fact's Sources, standing and history), the main view becoming presentation with links to the Fact ("✎ in Facts"), and editorial fields (completeness, abundance, code, name parts, lead Source, photos, ID note) edited in place. Claude leaned yes. Three mockups were built to answer exactly this: `/dev/mockups/gall-facts/:id?edit`, `/dev/mockups/genus-facts/:name?edit` (rank pages have no Edit mode today) and `/dev/mockups/species-facts/:id?edit` (in place of the species page's Names and placement panel and its 'Based on which Source?' dialog), sharing `FactEditMock`.

What happened next (d3b0 'The Fact inspector', Jeff 2026-11-07, and the inspector build): the Fact viewer and editor became one thing, the Fact inspector. Every Fact-backed value is a `fact_ref`; selecting it opens the inspector beside the page; in Edit mode the actions sit in the inspector, grouped by authority; no edit forms in the page body and no verb on every row; editorial fields stay in-place fields; and 'the Facts panel becomes the full record (history, withdrawn, superseded), not where editing must happen'. Jeff called the inspector 'the direction' and it is built on the Gall page; the Gall page's Facts section now starts closed behind 'Show the full record'.

So the matters suggest the inspector may already answer this question (edits begin and end in the inspector, not the Facts panel), but no matter records Jeff closing it. Options: (a) yes, the Facts panel as the edit surface, main view presentation (the three Facts-panel mockups); (b) the inspector as the edit surface and the Facts panel as the read-only full record (what is built on the Gall page); (c) something else for taxon and rank pages, which are still to be designed through the inspector. What it affects: how phase 'Edit model: one editor' rebuilds the editors for taxon, rank and Source pages, and whether the Facts-panel mockups (question c9e6) are still needed.
