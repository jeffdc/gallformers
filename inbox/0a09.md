Context (phase 2, f923 'Splits'): after an accepted split of A, each Gall on A that the splitting paper doesn't place gets one curator question, 'Which taxon induces this Gall now?' (each daughter, A in its narrow sense, or not known yet).

Chosen: a heuristic suggests a daughter from shared Hosts: the daughter whose Galls, by the splitting paper's statements, share a Host with this Gall (Catalog.split_suggestions/3). It is shown as the recommended option, worded 'a suggestion to check', and is never bulk-accepted: each Gall's answer is a curator's choice.

Why: it saves the curator looking up the Hosts for every Gall, but a Host overlap is weak evidence for which species induces a Gall, so it must not be applied wholesale. f923 decided split questions are per Gall, never per Fact.

Alternative: no suggestion (the curator decides each from scratch), or an automatic assignment by Host overlap (faster, but would silently re-point Inducers on weak evidence).

Code: Import.SplitQuestions (the question's proposal), Catalog.split_suggestions/3, the review_option recommended mark.
