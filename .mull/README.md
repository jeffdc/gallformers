# Old mull: read-only history

**Not a source of truth.** On 2026-11-09 this project moved to the new `mull`, whose data lives on the `mull` git branch and is used only through the `mull` CLI (see "Working with mull" in AGENTS.md). Plans, epics, items, questions, loose ends and ideas are there now.

This directory is the old tracker (`mull1`), kept so that links and citations still resolve:

- `matters/`: matters that weren't done when the old tracker was retired. Their statuses are stale: some describe finished work as open. The intake carried what's still live into the new mull, citing each matter, and left the rest behind.
- `archive/`: matters closed (done or dropped) in the old tracker.
- `docket.yml`, `sessions/`: the old tracker's working files.

Don't edit anything here, and don't track new work here. Code comments, item notes and inbox entries that say "matter xxxx" mean a file in this directory: `ls .mull/*/xxxx-*`.
