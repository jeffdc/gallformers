# Edit model: one editor

One edit framework, then every editor rebuilt onto it (Jeff agreed: framework first). All edits that can be inline are inline on the main pages, with one shared set of UI components, mechanics, validators and code, so a bug in editing is fixed once. Then a full audit of the whole system. It builds on the previous phase's back end (one ingestion path; one Gallformers Source whose changes are packages).

## Breadth

Fact-bearing pages are the Gall page and all of Gallformers' non-plant taxonomy (species, genus, family, every intermediate rank, section), plus a Source's own page and the review's Facts. Plant records are editorial (name, synonyms, range edited in place as editorial tray items, no Facts preview or evidence). Host-Gall is a Gall Fact.

## The Fact inspector is the direction

Jeff, 2026-11-07: "so much better than other designs I have tried". The Fact viewer and the Fact editor are one thing. Every Fact-backed value on a page (each Host, Trait value, range place, Inducer, alias, common name) reads as it does today, as a `fact_ref` (a quiet dotted underline, hover text "Who says so?"). Selecting it opens the `fact_inspector` beside the page: the Fact in words, its standing, and each Source's statement. Both are in `docs/design-system/components.md`; the Gall page is built this way and is the template for the other pages.

Decided:
- **Readers get the inspector:** provenance on demand is "every claim has a Source" made visible. One component, not a reader's and a curator's.
- **A side panel on wide screens (in the rail's place, sticky), a bottom sheet on phones,** beside the page, not replacing it.
- **Top to bottom:** the kind ("Host"), the value large, what it is of ("A Host of <Gall>"), the standing (Holds · Stated by N Sources; Unconfirmed when only Gallformers' undated original data states it; Withdrawn or Superseded with who says so), then **Who says so**, then **History**.
- **One template for every Source:** each Source a block, "{Source} says so" (or "says it isn't so") · its date, its words as written, up to two quotes (the rest counted), and the actions that belong to that Source. Gallformers is one of the Sources: the old site's data reads as Gallformers' own statement, "original data, undated".
- **Gallformers is pinned first, reading and editing alike,** then the other Sources newest first. (Changing order between modes was odd; bottom is the alternative if readers should see the literature first.)
- **Edit mode adds actions to the same inspector, grouped by authority.** Gallformers' block first, where the curator acts: Change…, Deny…, Add a note…; when Gallformers hasn't stated the Fact, its block says so and adds Confirm…. No empty "Gallformers says" section.
- **Fixing a reading is a level deeper,** since it is less common than Gallformers changes: the toggle "Found an error in a Source reading?" reveals "Fix our reading…" on every other Source's block; its form asks "What {Source} actually says", under that Source's authority at its date, with no Gallformers position.
- **No edit forms in the page body and no verb on every row:** actions exist only for the selected Fact. Adding is one Add per group (Add a host, Add a place, Add a common name; in Edit mode each Trait not recorded is an add), opening the inspector on a new Fact with the same statement step.
- **Editorial fields** (completeness, abundance, ID notes, photos) stay in-place fields, styled apart from Facts.
- **The Facts panel becomes the full record** (history, withdrawn, superseded), not where editing must happen. On the Gall page it starts closed behind "Show the full record"; its Facts no longer current open the inspector.
- **Discoverability:** the underline alone isn't discoverable, so readers get a dismissible hint ("Underlined values show the Sources that state them"), remembered per browser.
- **History** is a timeline at the inspector's foot: a disclosure "History (N)", each change to the Fact newest first in plain words (when, what happened, who: a curator's name or "import"); earlier Gallformers positions are here, "one click away, not separate voices". In Edit mode, Confirm… on a Fact no longer current makes Gallformers state it again.
- **One tray, grouped by authority,** whichever entry point: Gallformers, "Readings fixed: <Source>", Editorial; applying makes one package per group.
- Add from observation opens the inspector's observation state (the card, a warning when the observation's taxon isn't the Gall's Inducer, "Not Research Grade" made clear, proposals ticked and previewed on the page, photos as editorial tray items).

Open: question 4974 asks whether every Fact edit should begin and end in the Facts panel, the main view becoming presentation with links to the Fact (Jeff raised it, not a wish; Claude leaned yes). The inspector design above puts the edits in the inspector and makes the Facts panel the full record; whether that settles 4974 is Jeff's call.
