# Gallformers notes

Step 4 of the release order: the Gallformers ID notes, ~1,300 per-Gall notes from the old site (Source "Gallformers ID Notes", Source 58; ~400 characters on average, no dates; 1,299 in the dev data, 775 on undescribed Galls and 524 on described). It comes after the edit model's back end, because that phase decides where notes live and how Gallformers' statements are dated. All of the notes, undescribed and described, are processed before the public release, on preview with the rest of the backscan; decisions carry over through the replay log (Jeff, 2026-10-28).

The phase first reconciles the notes plan with the edit model, then builds what Jeff approves. The two disagree, and the reconciled plan is Jeff's call.

## What notes hold (decided by Adam and Jeff, 2026-10-17)

- No look-alikes concept: look-alikes are inherent in a matching set of Traits.
- Gallformers' statements of Fact: Hosts added from iNat Observations, "tentative" ones included (just Facts; the single Observation is their evidence); descriptions of undescribed Galls; where and when a Gall was seen (recorded occurrences, the `occurrence` Fact kind); adjudications of conflicts between Sources, with a reason.
- Commentary that isn't a Fact: summaries of the literature and of the state of knowledge, open hypotheses, pointers to people and resources. It stays as page content, outside the Facts.
- Passages copied from published papers belong to that paper as a Source.

## The notes plan (2026-11-06)

- Each Gall's note is shown whole on the Gall page ("Notes on ID and Taxonomy"); Facts are drawn from it where it states them; commentary stays text.
- **Undescribed Galls:** their Facts come from the current data, already credited to the Gallformers Source by the catalog migration (every legacy Fact of an undescribed Gall confirmed as Gallformers' own, dated the run's day, at cutover the cutover date; Jeff: Gallformers is the only Source for them, and notes were never required to support Facts). Their notes stay as text, with no LLM extraction.
- **Described Galls:** code writes the patterned statements ("<plant> added (tentatively) as a host based on [observation]" as Host Facts with the observation as evidence; "observed in <place> in <month>" as occurrence Facts, place matched to our places, the month being when it was seen, not a season Fact). The ~200 notes with taxonomy or ruling sentences need judgement, by an LLM in chunks or a curator queue. Comparisons, references, remarks on the inducer and the state of knowledge stay text.
- Running every note one by one through the LLM pipeline (≈$700-1,700) is not the approach (Jeff, 2026-11-05): sort with code, handle what code can deterministically, and leave only a minority for an LLM pass, batched.
- **Taxonomic remarks** stay text: Gallformers is a taxonomic authority only as a rare exception, so a remark's position comes in through the paper it rests on, in the backscan.
- **Splitting notes apart:** the Fact-bearing statements separated from the commentary, so the note text that remains is the ID guidance and commentary.
- **Dates and conflicts:** note Facts dated about now (the exact date is unimportant). A note Fact that would supersede or withdraw a Fact from the literature goes to a curator, except a recorded occurrence outside the Gall's range, which is added automatically and the range updates. A Gall's range may widen within the union of its Hosts' ranges; beyond that a Host's range must be expanded.

## What the edit model decided later (Jeff, 2026-11-07)

- ID notes are 100% editorial: editorial prose, nothing to do with Facts.
- Notes leave the Gallformers Source, as editorial records on the Gall.
- Old ID notes are processed into changes (packages of the one Gallformers Source) carrying the notes' own dates. The old site's data is the Gallformers Source's undated base.
- The editorial fields, ID notes included, stay in-place fields on the page, styled apart from Facts.

The same session's audit found that note saves (`Sources.store_note`) are audited but not replay-logged, a cutover risk the edit model's back end closes.

These conflict with the plan above in what a note is (Gallformers' document Facts are quoted from, vs editorial prose), where it is stored, and how note Facts are dated (about now, vs the notes' own dates, which the legacy notes don't have).

## Done when

Every note is handled before release per the reconciled plan: its Facts, if any, are Gallformers statements made through the one ingestion path with the dates the plan settles; the rest stays as editorial text on the Gall, shown on its page and edited in place; and every write is in the replay log.
