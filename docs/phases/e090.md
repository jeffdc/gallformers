# Gallformers notes

The old site's ~1,300 per-Gall notes (Source "Gallformers ID Notes", Source 58; no dates; 1,299 in the dev data, 775 on undescribed Galls and 524 on described). Handled before release, on preview with the rest of the Sources.

## Analysis first

**Nothing about the notes is decided for sure until we've seen what's in them** (Jeff, 2026-11-15). The first step is an analysis of what the notes actually contain. The categories, and how each is handled, are decided with Jeff from that analysis.

The starting hypothesis (Jeff, 2026-11-12), to be confirmed or changed by the analysis:
- **Undescribed-Gall descriptions:** processed as Sources, adding Facts as normal (Jeff, 2026-11-15). They may or may not confirm what the old site's data already holds.
- **Pure ID notes:** editorial, an ID Notes field on the Gall, attached to no Source.
- **Other:** to be worked out once it's visible.

## What's already decided

- **All of the old site's data comes over as Gallformers legacy data** (Jeff, 2026-11-15), before any note is processed.
- **Code sorts the notes deterministically and repeatably** into the decided categories (Jeff, 2026-11-12). Nothing is imported blindly.
- **How to date the Facts from undescribed-Gall notes is its own analysis** (Jeff, 2026-11-15). Its answer also decides whether the migration keeps its step that confirms undescribed Galls' Facts as Gallformers statements (*Migration through the import*, item 15ca).
- **Notes are processed through the import like any Source**; nothing writes their Facts directly (plan doc, *One write path*).
- **Running every note one by one through the LLM producer is not the approach** (Jeff, 2026-11-05): sort with code, handle with code what code can, and keep any LLM pass to a batched minority.

## Done when

- The analysis is done and Jeff has decided the categories and how each is handled.
- Every note is sorted by tested, repeatable code into those categories.
- The undescribed-Gall notes are processed as Sources through the import, with the dating Jeff decides.
- Pure ID notes are in the editorial ID Notes field on their Gall.
- Every other category is handled as decided.

Sources: matter 20e5; the 2026-11-12 history audit; Jeff, 2026-11-05 to 11-15 (decision log).
