# Collecting Source documents

Every Source the 7a50 fates say to process needs its document in the private bucket, verified by a curator and converted, before anyone reads it with an LLM. This phase builds that on today's production site, so curators beyond Jeff and Adam can help gather the documents while the rest of taxogall is built (Jeff, 2026-11-21; design and decisions on item 274b).

## Built once, for both sites

The old site is in maintenance mode, so building there is low risk. What this phase builds behaves the same on the old site and the new one, and moves from `main` into `taxogall` cleanly: shared code such as `Gallformers.Storage.Private` is one module on both (today it exists only on taxogall). Its state lives mostly in the private bucket, so `main` adds little or no schema and nothing clashes with taxogall's tables when `main` is merged in. This is the one exception to the plan's rule against building alongside the old system (Jeff, 2026-11-21).

## What curators see

A Sources work page lists every Source and its state: needs document, awaiting verification, being converted, conversion failed, done, or not to be processed (the 7a50 fates that keep a Source as a reference only). There are no claims. A curator picks a Source and uploads its document, or gives a URL for a web page. The upload goes from the browser straight to the bucket through a signed URL for the exact key, as image uploads already do (`Storage.Images.presigned_upload_url/2`). The curator who provides a document may verify it themselves.

- **Automatic checks** on arrival: a PDF or saved web page under a size limit, not encrypted or DRM-locked, not an exact duplicate of a document already held, with its page count shown to the curator.
- **Web pages** are given as URLs. A job has the Sprite fetch the page, store the HTML as captured with its URL and access date, and convert it; the curator then verifies the captured page. A page that won't fetch cleanly (built by JavaScript, behind a login, blocking automated fetches) is uploaded as saved HTML or a PDF, with the URL and date given by hand. A Source takes any number of page documents, each fetched, dated and verified on its own.
- **A garbled conversion** stops and goes back to the curator.

## Prefetching

Sources whose record already links to their document are fetched ahead of time: a job fetches what the link points to, runs the checks and converts it, and the Source waits as awaiting verification. One fetcher per site (BHL, Internet Archive, HathiTrust, DOI with Unpaywall, plain web pages), built in order of how many Sources each covers, rate-limited and within each site's terms. Paywalled Sources, links that aren't the document, and Sources not to be processed are left for curators.

## Conversion on a Sprite

Conversion runs automatically on a Fly Sprite, started by an Oban job: the app machines (1 GB) can't hold a conversion, which peaks at 2 to 6.5 GB. The job starts the command through the Sprites API with a signed download URL for the original and signed upload URLs for exactly the files the conversion writes, `result.json` last; a follow-up job checks the bucket for `result.json`, so a long run (Felt 1917 took 21 minutes) survives a deploy. The Sprite holds no AWS keys or app credentials, and the app's Sprites token is limited to `gf-convert-*` Sprites. The Sprite pulls the producer from GitHub at the deployed commit, pinned, so a conversion's version names the code that made it.

Before the Sprite converts anything real, the converter must give the same result on any machine: today its OCR choice depends on `/usr/share/dict/words`, which the Sprite lacks, so it silently converts differently (backlog bug, item 274b). A conversion's version records the word list and the tool versions (Tesseract, Ghostscript). The first trial's numbers and setup are in `services/import-producer/output/sprite-convert-2026-11-21/LEARNINGS.md` (local).

## The bucket

The private bucket is laid out by Source (decisions on item 274b): a document lives at `sources/<source id>/documents/<sha256>/` with `original.<ext>`, `provided.json` (who, when, how, a web page's URL and access date), `verified.json` (who, when) and `convert-<version>/` (`document.json`, `document.txt`, `convert.json`, `ocr.pdf` for scans). Preview and production share it with no environment prefix, so preview sees every document collected here at once. Versioning is turned on for the bucket (an OpenTofu change Jeff applies).

## Working rules

Agents give Jeff the exact Fly and Sprite commands and run one only once Jeff has approved it (as in the 2026-11-21 Sprite trial), and never read, set or guess secrets.

## Done when

- Curators can sign in to the production site, find any Source on the work page, and upload, verify and see the conversion of its document, or give a web page's URL and verify the captured page.
- The automatic checks and the garbled-conversion stop work, and a failed conversion shows its reason.
- Prefetching has run for the Sources whose links are the document, through the fetchers built.
- The converter gives the same result on the Sprite as on a laptop, and records its version.
- The bucket's versioning is on, and the code moves into taxogall unchanged.
