# One write path

Build the architecture rule in the plan doc (*One write path*, Jeff, 2026-11-12): for any data, one editing screen plus the import, both calling the same underlying code to validate, write and read it. This phase builds the back end of that rule and fills in the interfaces the UI phase stubbed. *One editor* then connects the finished screens to it.

## Terms

- **Source:** anywhere Facts are derived from.
- **Gallformers legacy data:** the old site's data. Undated, so every dated statement from any other Source overrides it. A Fact supported only by it shows as unconfirmed.
- **Gallformers:** the curators' own statements of Fact. Each is dated by its change.
- **Change:** one package of the Gallformers Source (a curator's edits, applied from the tray): small, timestamped, audited (who).
- **Reading:** how Gallformers read a Source, the Facts it took the Source to state, with its words as written. A misreading is fixed under that Source's authority, at its date. Not a **Correction**, which the domain model defines as a Source's published erratum (a newer Source).
- **Editorial data:** data that isn't a Fact (plants, a Gall's editorial fields and name parts, ID notes, images, keys, articles). Exactly which data is editorial is a design item in the plan doc.

## The rules

1. **One writer per kind of data.** Each kind (a Fact kind, a plant, a Gall's editorial fields, an image, a key, a Source record) has exactly one function that validates and writes it, and one that reads it. The editing screen, the import, the migration and replay all call that function. No second code path writes the same data.
2. **A Fact edit is an ingestion.** A curator's edit under the Gallformers Source is a change: a package of that Source through the same code path as a paper's import, with the same rules. It applies immediately if it is valid (Jeff, 2026-11-12).
3. **Manual editing is one of two things:** correcting how an accepted Source was read, under that Source's authority and at its date; or a change under Gallformers' authority. No curator edit is credited to a paper.
4. **Any Source may state any Fact.** The literature is the usual authority; Gallformers may state any Fact, taxonomic included.
5. **Sources never reference each other formally.** A curator may write "Weld (1959)" in a statement's text; it stays text.
6. **Two Gallformers Sources** (Jeff, 2026-11-14): Gallformers legacy data (undated) and Gallformers (dated changes). A newer Gallformers change replaces Gallformers' earlier word on the same Fact; recency between Sources is unchanged.
7. **Plants just go in**, through their one writer, with no Facts (Jeff, 2026-11-12).
8. **Split and lump are taxonomic acts, so Facts,** under the authority of the Source whose statement decides them.
9. **Delete** is only for data added by mistake or testing.
10. **Audit is underneath.** Every write is recorded by the audit layer against its actor; code names the actor and nothing more.
11. **A package applies all or nothing** (Jeff, 2026-11-15): every part of it lands, or none does.
12. **Replay is mechanical.** Because every write goes through its one writer, replay re-applies the same writes in order. No per-kind replay code (Jeff, 2026-11-12).

## The tray

One tray, items grouped by authority. An ordinary edit is a Gallformers change; a fix of a Source's reading is under that Source's authority. Applying makes one package per group (one Gallformers change, one package per Source whose reading was fixed), all through the one ingestion path. Editorial edits apply through their own one writers.

## What this phase builds

- **An inventory of every write path, then one writer per kind of data.** Today there are many: seven editing surfaces, and a Gall's Host can be changed five ways, a plant's range five ways, a plant's name four (state report `2-editing.md`). Five kinds are also written by the migration's own SQL (Host ranges, WCVP links, images, keys, generation-group links; study `6-migration-via-import.md`).
- **The interfaces the UI phase stubbed,** filled in on those writers.
- **Every Fact write through a package.** That includes the direct Fact writes found on 2026-11-07 and 11-09: "Based on which Source?" (retired: a curator's edit is a Gallformers change, a misreading is a reading fix), synonym decisions in review that change the non-plant tree with no statement, Source corrections, merge and rename aliases, split answers, vocabulary term moves and placements outside apply.
- **Restating a Fact carries the earlier statement's evidence forward** (today a new Gallformers statement wipes a note-derived quote).
- **Statement dates become timestamps** for Gallformers changes. Standing between Sources still compares at day precision.
- **ID notes leave the Gallformers Source** and become an editorial field on the Gall (Jeff, 2026-11-12).
- **History views read from packages:** the Gallformers Source page's changes, a Fact's history.
- **`cited_source_id` and its attribution field removed** (stored, never read; they break rule 5).
- **One name and authorship comparison on every path** (today "(Weld 1959)" and "(Weld, 1959)" compare differently by path).
- **The audit layer complete:** the Source records and Host ranges tracked like the other tables (item c350's gap), and every write naming its actor. Find the cause of the unexplained "audit conflict" crash seen on 2026-11-07 (backlog bug 0162).
- **Packages applied all or nothing.** Today each batch of a package commits on its own (`import.ex` about 2928-2993), so a Source's taxonomy can land while its Gall part is held.
- **Replay made mechanical:** one replay of the same writes in order replaces today's 22 per-kind replay pieces, and covers what they miss (Gall editorial fields and name parts, ID notes, photos, content pages).

The task list is planned first, as one-session tasks Jeff approves as items.

## Done when

- Every kind of data has exactly one writer and one reader, and the editing screen, the import, the migration and replay all call it.
- Every Fact write in the app goes through the one ingestion path as a package of some Source; curator edits under Gallformers apply at once when valid; no curator edit is credited to a paper.
- Gallformers legacy data and Gallformers are the two Gallformers Sources, legacy undated and changes timestamped.
- ID notes are an editorial field on the Gall; no attribution carries a cited Source; the authorship comparison is one rule.
- The audit layer tracks every table written, and replay re-applies every kind of write through the same writers, with no per-kind replay code.
- A package applies all or nothing.
- Every interface the UI phase stubbed is real.
