# After release

Once production is stable on the new back-end, retire what is left of the old system and make the docs describe the new one.

## What to do

- **Drop the old tables.** These are the `species`-centric model's tables, which only the catalog migration reads until cutover:
  - `species`, `gall_traits`, `alias`, `alias_species`;
  - `taxonomy`, `taxonomy_alias`, `species_taxonomy`;
  - `gallhost`, `species_source`, `gall_range`;
  - the nine `gall_*` Trait joins and the nine old Trait vocabulary tables.

  `image` and `host_range` gained typed `gall_id` / `taxon_id` columns beside `species_id`; drop `species_id` when the old code goes. Legacy code is removed on `taxogall` as each piece is replaced, so little old code should remain by then. Add each module deleted here to `test/support/retirements.exs`.

  The test database is still built from old-style seed rows: `priv/repo/test_seeds.sql` is converted by the catalog migration (see `CLAUDE.md`). Dropping the old tables therefore means first giving the tests seeds for the new tables. `b5bd` M1 planned this as "rewrite `priv/repo/test_seeds.sql` for the new model".
- **Audit the `source` table with Carbonite.** Today only `source_documents` and `source_corrections` are audited. Creating a citation on the spot (`Sources.create_citation/2`, via `Import.record_source_created/2`) runs in an audited transaction that records no row change, and it is listed as "Added a Source" in the change log. Track `source` in a migration (`Gallformers.Audit.Migration.track_table/2`).
- **Replace the old domain docs:**
  - `docs/domain/general.md` and `docs/domain/admin-domain-reference.md` describe the old model. Replace them.
  - Update `CLAUDE.md`/`AGENTS.md`: its domain-model section says the old tables stay until cutover.
  - Update the admin onboarding and the runbooks that assume the old tables, e.g. `runbooks/restore-deleted-gall.md`.
- **Realign the test-suite inventory** (the testing-philosophy alignment list) with taxogall's suite. About 10 of the test files it lists are deleted on taxogall, and its inventory describes the old back-end.
- **Review records left with no Facts for removal**, old genus-level Hosts included, once most Sources are processed (Jeff, 2026-11-05: nothing before then).
- **Fix wrong Host ranges on the Host** (rule 1: plant ranges are editorial). The migration made every Gall's range its Hosts' union, so a wrong Host range now shows as a wrong Gall range.

## Deferred features (not in this phase unless Jeff pulls them in)

- Search and the API over Source terms. The v2 API doesn't expose trait sub-terms, which would be an API contract change. Site-wide search still searches names only.
- The PDF page view of a Source.

## Done when

- No old table or `species_id` column remains, and nothing reads them.
- `source` is audited.
- The domain docs, `CLAUDE.md` and runbooks describe only the new model.
- The test inventory matches the suite.
- The no-Facts review and the Host-range fixes are done.
