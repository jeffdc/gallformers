# Inventory: tables, cards, badges, page structure

Every usage of the table, container, badge and page-structure components, taken from the code on 2026-11-05 (design-system branch). A replacement keeps every behavior here unless a change is approved and recorded under "Approved changes". Paths are under `lib/gallformers_web/`.

## Findings

- No table uses a LiveView stream; no table has a sticky header.
- **No callers:** `species_card`, `tabs` (and its Tabs hook, which has a JS test), `back_link`, `abundance_indicator`, `data_completeness_indicator`, `edit_button`; the new `data_table`, `gall_card` and (outside the admin shell) `page_header` aren't used by app pages yet.
- **Bug:** vocabulary_live 512 uses `<.header>` *and* passes `page_title="Vocabulary"` to the admin shell: two h1s.
- **Inconsistencies to settle:** sort parameter `phx-value-column` almost everywhere but `phx-value-field` in host_live (the new `data_table` sends `field`); sort glyphs ↑/↓ vs ▲/▼ (host_live); four empty-state forms (separate gray box, colspan row, replacement block, `<p>` below); pagination in memory, DB-backed (source index), URL-backed (host_range) and hand-rolled (host galls); three admin tables bypass `gf-table` (key index, host_range, images).

## Must preserve

- **Tables:** heads centered by default, cells left and top-aligned; dark (admin) and light heads; compact and dense; zebra default only for `.table`. Sorting: `sort` with `column` (or `field` on host), the toggle rule, the active glyph, resetting page and selection on sort (search, host). `species_table` internal sort, nil = unsortable, nil common names last, `url_prefix <> id`, the shared genus sort. Row and table ids and `data-role` cells listed above; glossary row anchors. Per-cell `JS.navigate`; the search page's selection highlight and window keyboard navigation. Selection: taxonomy browse with bulk move; host_range select-all, disabled while processing; images copy mode (SRC row, tints, Esc, `phx-target`). Inline editing (vocabulary) and the users switch. Row actions (`table_actions`/`action_button`, `target=_blank`, `confirm=`, dangerous modals). Mode-dependent columns. All four empty-state forms with their messages. Each site's pagination semantics.
- **Cards:** title bar, icon, actions; body padding (the Random Gall bleed); untitled padding; `class`/`id` pass through; ids `images` (anchor and test), `editorial`, `name`, `note`, `range-exclusions`, `related-genera-filters-*`; `overflow-visible` on taxonomy new; `gf-card` collapsible sections and `data-role` hooks.
- **Badges:** success/warning/info including dynamic; `data_complete_badge` labels, three tooltips, `cursor-help`; chip `size="sm"` + `data-role="chip"`; typeahead chip removes (string event, `phx-value-type`/`-id`, mousedown guard); destination badges; `gf-pill` matching.
- **Page structure:** the slot-over-attribute title rule, rich titles and breadcrumbs, no dashboard title, fix the vocabulary double h1; `admin_edit_layout`'s back link, conditional public link, intro, width (and the two hand-copied bars); breadcrumb name-based URLs, link-vs-text, separators, genus description, nil guard; `record_metadata` format and nil handling; `see_also` (nothing when undescribed, per-type logos, name parsing, new tab); `pagination` texts, disabled ends, the function contract, clamping callers; retire `tabs` and its hook test together.
