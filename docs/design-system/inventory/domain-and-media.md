# Inventory: images, maps, Sources, names, keys, region

Every usage of the domain components and what each relies on, taken from the code on 2026-11-05 (design-system branch). A replacement keeps every behavior here unless a change is approved and recorded under "Approved changes". `DDC` is `lib/gallformers_web/components/data_display_components.ex`; other paths are under `lib/gallformers_web/`.

## Findings

- **No callers:** `source_citation`, `source_list`, `species_synonymy`, `host_list` (DDC). Retire after confirming.
- **Bugs not to copy:** the gallery's source link, " © " separator and info/lightbox source link render only if the *first* image has them; the lightbox always says "Image by"; `[data-license-tooltip]` matches nothing; `source_title` is never supplied. The places tree builds leaves with `rank: nil` (`places.ex:521`) and `tree_components.ex:120` calls `taxon_name` with the default rank, so place names are probably italic. Gall page Source excerpts are rendered inside a `<button>`, nesting glossary `<a>` links in a button (invalid HTML). Host pages wrap the gallery in `:if={length(@images) > 0}`, so its empty state and "Add images" never show there.

## 1. Images

### `image_gallery` (DDC:109) + ImageGallery hook

Images as maps or structs (atom or string keys): `src, alt, caption, creator, license, licenselink, sourcelink, attribution, source_title, uploader, lastchangedby, id`; `edit_href` + `current_user` (edit and "Add images" only for admins); `id`, `class`, `no_image_src`. Root `phx-update="ignore"`, `tabindex=0`, `data-images` JSON. Main image `loading=lazy`, `max-h-[400px]`, click opens the lightbox; ‹ › and "n / N" only with 2+ images; italic caption hidden when empty; "Image (→ sourcelink) by {creator} © {license (→ licenselink)}"; ⓘ opens the info `<dialog>` (Source, License, Attribution, Creator, Uploader, Last Modified, Caption); full-screen lightbox `<dialog>` with its own attribution and controls; empty: `no_image_src` or "No images available" + admin "Add images".

Hook: ArrowLeft/Right wrap (only while focus is inside the root); Escape closes the dialogs (`showModal()`); every move rewrites the `data-*` slots and pushes `gallery_index_changed {index}`. No swipe, no thumbnails, no focus return.

Sites: gall_live 609 (`gall-images`, edit `/admin/galls/:id#images`; tests at gall_live_test 215, 224; no-op handler 282), host_live 447 (`host-images`, edit `/admin/taxonomy/:id#images`, `no_image_src=/images/noimagehost.jpg`; handler 142), source_live 230 (`source-images`, no current_user; handler 105).

### Admin `ImagesComponent` (live/admin/images_component.ex)

Mounted in gall_live/edit 633 (`<.card id="images">`, `owner={{:gall,id}}`) and taxonomy_live/edit 817 (`taxon-images`). Grid/table toggle; SortableImages drag-and-drop (`data-image-id`, `reorder_images {order}`, mouse only); the first image is the default (badge + maroon ring); unattributed warnings (banner + per-image ring/badge, `Attribution` rules). **Remount lesson:** the grid id is `"#{@id}-version-#{@images_version}"`, bumped after a reorder so the DOM matches the server. Uploads: ImageUpload hook (`phx-update=ignore`, ≤20 JPG/PNG): `request_presigned_urls` → `presigned_urls` → XHR to S3 with progress → `uploads_completed` → `upload_complete`/`upload_error` → `refresh_images`. Modals: view, edit (attribution rules; Source search fills license, link and creator; canonical license links read-only), delete (S3 first), copy metadata (Escape cancels copy mode). iNaturalist import (InatImportComponent): idle → fetching → picking → importing → done, ~1 s between photos, license from `Licenses.url`, `send_update` on completion. ContentImageManager (key and article forms) uses SortableImages and ContentImageUpload; ArticleImageUpload in the article form.

## 2. Range maps

### `range_map` (DDC:1185) + RangeMap hook

Codes (ISO 3166-2 or alpha-2): `in_range` (required), `excluded_range`, `inherited_range`, `introduced_range`; flags `editable`, `navigable`, `place_mode`; `id`, `class`, `tiles_url`, `empty_text`, `max_bounds`, `bounds`, all as `data-*` on a `phx-update="ignore"` root (`min-h-[400px]`, "Loading map...").

Hook: MapLibre 6 + PMTiles (worker URL with version query); WebGL2 missing → "Map unavailable in this browser"; tile error → "Map data unavailable". Layers: ocean, `countries-fill`, `subdivisions-fill`, borders with zoom-interpolated widths, lakes, canvas-hatched introduced layers. Colors: documented #228B22, country-level #90EE90, excluded #FCA5A5 (editable only), blue in place mode. Effective sets: excluded removed from in-range and inherited; in-range beats inherited.

Framing: `WORLD_BOUNDS [[-180,-58],[180,84]]` first; on load `fitToRange`: no data → world; else server `data-bounds` (read live; padding 40, maxZoom 5; from `Places.get_bounds_for_codes(range ++ inherited)`); else a bounding box from `querySourceFeatures`. b9516e1d removed an `isStyleLoaded()` guard that broke framing and added a 0.01° antimeridian tolerance (1,646 galls were mis-framed). Open: introduced ranges widen the frame. `minZoom 1`, `boxZoom false`.

Controls: "Natural Earth" attribution, zoom, fullscreen with a 2 s "Press Esc to exit fullscreen" hint. Tooltips (hover only): "**Name** (CODE) — Documented / Country-level record only / Excluded / Not reported" + "(Introduced)"; place mode drops the status; countries only when no subdivision is under the cursor; "— Click to edit range" when editable; HTML built from tile data, unescaped. One map-level click handler (`pickSubdivisionCode` prefers hyphenated codes, because tippecanoe merges features at low zoom); editable → `toggle_region` or `toggle_country`; navigable → `navigate_to_place {code}`. Server events `range-update`, `range-zoom-to-country`, `range-zoom-out`; `updated()` recolors and re-frames only when new codes appear (d37e16ed), keeping the drill-down country in view. The empty overlay counts excluded codes too (58cb8cf2).

Sites: gall_live 533 (`gall-range-map`, `h-[300px]`, navigable, `:if={not @range_unknown?}`; the "Not an occurrence map" alert above; "Range unknown — no host range data available."; handler 329), host_live 391 (`host-range-map`; 173), place_live 81 (`place-range-map`, `place_mode`, `h-[60vh]`; 37), admin gall_live/edit 692 (`exclusions-range-map`, all four lists, editable, with PlaceDrillDown; 181, 185, 233, pushes 420/460), range_editor 610 (`host-range-map`, editable, CountryDrillDown, `min-h-[500px]`; 125, 135, pushes 151/318; from taxonomy edit 722 and new 690).

### `range_map_legend` (DDC:1062)

`mode`: `:public` (Documented, Country-level, Introduced hatched), `:host_admin` (+ Out of Range), `:gall_admin` (In Gall Range, Country-level, "Host Only" red, Not in Range, two hatched). The red swatch says "Host Only" where the tooltip says "Excluded". Sites: gall_live 547 and host_live 401 (public, only with inherited or introduced codes), admin gall edit 687, range_editor 603.

## 4. Names and taxonomy

- **`taxon_name`** (DDC:46): `name`, `rank` (default "species"; "auto" infers), `class`, `genus_placeholder` ("(genus-level)" with a title). Italics through `TaxonName.segments` (binomial and infraspecific epithet italic; rank words, authorities, parenthetical qualifiers upright; Unknown placeholders upright), joined into one string. `italicize_rank?` true for species, genus, section. Used across ~40 sites (gall_card, key_components, tree_components, rank pages, facts_components, home, intermediate, family, genus, source, search, gall, id, host, admin taxonomy and host range). home_live 175 and the ID host results rely on the bracketed aliases staying upright.
- **`taxonomy_breadcrumb`** (DDC:654): `family`, `intermediates`, `genus` (+ description), `section`, `species`, `show_family`, `show_genus`; bold labels, `|` separators; links by name (`/family/`, `/:rank/`, `/genus/`, `/section/`); the id decides link vs text; " - description" when not blank (04440fb8); from `LineageBreadcrumb.from_lineage`. Sites: gall_live 469, host_live 258, genus_live 296 (`show_genus={false}`), section_live 121, intermediate_live 141. Replaced by `page_header` crumbs.
- **`tree_browser`** (tree_components 24): `id`, `nodes`, `expanded` (MapSet), `search_query`, `show_search`, `show_controls`, events `on_toggle`, `on_expand_all`, `on_collapse_all`, `on_search`. Search form `#{id}-search-form`, field `query`, 300 ms; "Expand All | Collapse All"; a node with a `:nodes` key is a branch (caret with `phx-value-key`, rotates); level 0 maroon; child count, "(description)", external link; leaves link; "No matching items found." / "No items found."; no tree roles. Server (browse_helpers): `filter_tree` keeps matches and ancestors of matches; `smart_expand` expands branches with ≤5 children when ≤3 top-level families remain; Expand All over the filtered tree. Sites: galls_browse 119, hosts_browse 66, places_browse 66 (events `toggle_node`, `expand_all`, `collapse_all`, `search`).
- **Glossary:** `glossary_tooltip` (ui_components 786; hover-only; one caller gall_live 391 for the generation term). Auto-linking (`markdown.ex`): ETS cache 15 min, "gall" excluded, case-insensitive whole words, longest first, never inside tags or links, `<a class="glossary-link" href="/glossary#word">`; used by `render!` (gall_live 704, 790; article_controller 32) and `linkify_glossary_terms` (glossary_live 169, filter_guide_html 45).
