# Inventory: the Host and Source pages

The behavior contract for the public Host page (`/host/:id`) and Source page (`/source/:id`), taken from the code on 2026-11-05 (design-system branch). A redesign may change how they look. It must keep every behavior listed here unless a change is explicitly approved and recorded below. Line references: `H` is `lib/gallformers_web/live/host_live.ex`, `S` `lib/gallformers_web/live/source_live.ex`, `HP` `lib/gallformers/taxa/read_models/host_page.ex`, `LER` `lib/gallformers_web/plugs/legacy_entity_redirect.ex`, `FC` `lib/gallformers_web/components/facts_components.ex`, `UI` `ui_components.ex`, `CC` `core_components.ex`, `DDC` `data_display_components.ex` (components under `lib/gallformers_web/components/`). The shared components (`image_gallery` + ImageGallery hook, `range_map` + RangeMap hook, `range_map_legend`, `taxon_name`, `taxonomy_breadcrumb`) are inventoried in `domain-and-media.md`; the breadcrumb's link format is in `rank-pages.md` §1. This file covers how these two pages use them. There is no design-system pattern or mockup for either page yet (`patterns.md` names "a Host, a Source" among the detail pages only).

## Findings

- **Not found is a 200, not a 404.** Both pages render a red box ("Invalid host ID", "Host not found", "Invalid source ID", "Source not found") with title "Host Not Found"/"Source Not Found" and `page_noindex: true` (H:22-45, S:22-55). Matter 803b Task 5 planned "404 for a non-plant or missing ID". The red box is Tailwind palette classes (`bg-red-50 … text-red-700`). The `@host == nil` / `@source == nil` "not found" branches in `render` are unreachable: `error` is always set when there is no record (H:462-466, S:295-299).
- **The Host page has no h1.** The plant's name is an `h2` (H:234), its sections `h3`. The e2e browse test asserts `h2` with the name (`test/e2e/browse/browse_test.exs:72, 92`). The Source page's title is an `h1` (S:158).
- **The Host name is a hidden link to the ID tool.** The h2 links (`href`, full load) to `/id?h=<URI.encode(name)>` (H:235-240), which opens the ID tool with this Host chosen. Nothing says so; it reads as a plain heading with a hover underline. `URI.encode` leaves `&`, `+`, `=` unescaped (not `encode_www_form`); no real plant name has them.
- **Galls on the plant's genus are not shown.** `Catalog.list_galls_for_hosts([id])` takes Galls with a current `host_of` Fact on exactly this taxon (catalog.ex:941-954). Galls whose Host is the genus (old "Quercus spp.") appear only on the genus page's "Galls on the genus as a whole"; nothing on the Host page points there except the breadcrumb's genus link. Likewise a variety's page does not list its species' Galls, nor the species page its varieties'.
- **The breadcrumb skips the species of an infraspecific Host.** `LineageBreadcrumb.from_lineage/1` keeps only family, intermediates, genus and section, so a variety's page never shows or links its species (which has its own `/host/:id`).
- **The old `?source=` deep link on Host pages is gone.** e3010f6f added `/host/:id?source=<id>` (open that Source's description); 67378c93 dropped plant Sources (803b decision 1) and `handle_params` with them, so inbound links with `?source=` load the page and ignore the parameter.
- **Sort and pager crash or misbehave on crafted events.** `sort` with a field outside `name datacomplete` has no matching clause (H:146-163). `next_page` with no Galls sets `current_page` to 0 (H:135-139); harmless, as the pager is hidden then. `synonymy_page` and the Source `page` event clamp with `max/min` on whatever `page` is; a string is not rejected (Erlang term order makes it the last page). Harmless to real users.
- **Two pagers on one page.** The Host Galls table has its own inline pager ("1-10 of N", Previous, "Page X of Y", Next; `prev_page`/`next_page`, H:351-380); the synonymy table under it uses the shared `pagination` component ("Showing 1 to 10 of N results", H:431-439). The Source page uses `pagination` (S:261-269). Page state is a socket assign on both pages: not in the URL, lost on reload.
- **The Complete column is icons only.** A green `ph-check` or red `ph-x` with no text or `aria-label` (H:328-337); screen readers get nothing. The sortable headers are `<th phx-click>`: not focusable, no `aria-sort`, mouse only; the arrows are "▲"/"▼" text (H:212-218, 284-307).
- **The data-complete badge explains itself only on hover** (`title` on a `cursor-help` span, CC:521-533): no touch or keyboard access to the tooltip.
- **Two rules before See Also.** The Host page renders `<hr class="border-gray-200 my-4" />` (H:457) and `see_also` renders its own `<hr>` first (UI:639).
- **Generic image alt text.** Every Host image's alt is "Host plant image" (H:123), every Source image's "Image from source" (S:122); the caption is not used.
- **The Host page's gallery hides its empty state.** `:if={length(@images) > 0}` (H:443) means `no_image_src="/images/noimagehost.jpg"` and the admin "Add images" link never show (noted in `domain-and-media.md`). The Source page always renders the gallery, so most Sources show a grey "No images available" box in the right third (S:229-231, DDC:428-434), and never "Add images" (no `edit_href`).
- **Source images don't say what they show.** `Images.list_images_for_source/1` orders them by the Gall's or taxon's name (images.ex:311-327), but `format_images` keeps only credit fields and the caption (S:109-133); the Gall or plant an image belongs to is not shown or linked.
- **The Source page shows only the old columns.** Title, `author`, `pubyear`, `link`, `citation`, `license`, `licenselink`, `datacomplete`. The new descriptive fields (`kind`, `authors` list, `authored_date`/precision/as written, `doi`, `url`, `isbn`, `license_value`, `license_as_written`) are not shown (source.ex:69-81).
- **Retraction is invisible on the Source page.** Nothing shows `retracted_on` or the notice Source (`retracted_by`). The only trace: each of its Facts left without other support shows a bare "retracted" mark in "What this Source says". Meanwhile "Connected Galls" counts only Galls of **current** Facts (plus legacy citations and notes, catalog.ex:972-983), so after a retraction a Gall known only through Facts disappears from Connected Galls while its Facts stay listed under "What this Source says". The two sections can disagree in general: Facts that are withdrawn, superseded or unsupported are listed (FactsView carries every standing, facts_view.ex:159) but their Galls aren't connected.
- **Unsupported Facts are public here.** A Fact left `:unsupported` by an undecided conflict is hidden everywhere else, but the Source page lists it with an "unsupported" mark (FC `fact_mark`). Standing marks are the raw atom ("withdrawn", "superseded", "retracted", "unsupported") with title "This Fact's standing in Gallformers".
- **"What this Source says" shows only gall Facts.** `facts_for_source/1` reads attributions of kinds `gall_*` (import.ex:2078-2079); taxonomic Facts a Source states (synonymies, new taxa, `taxon_*`) are not shown. Hosts and Inducers in Fact rows are names, not links; only the Gall headings link.
- **Without JavaScript the Facts never load.** They are read on the connected mount only (S:90-96), so the dead render (and a crawler) shows "Loading…" with a spinner in that section. Deliberate (the comment's reason: the first render has the Source and its Galls without waiting), but the spinner never resolves without a socket.
- **No way back to Sources.** There is no public Sources list (`/sources` is admin only, router.ex:140), no breadcrumb, and no link from a Source to anything but its Galls, its own URL and its license.
- **Canonical is a `<meta name="canonical">`**, not `<link rel="canonical">` (`seo.ex:48`); search engines ignore it. Site-wide, not specific to these pages.
- **Oversized IDs probably raise.** `Integer.parse` accepts any size and `+5`. On `/host/`, the plug only handles 1..bigint max (LER:23-33); a larger number reaches `Repo.get` and likely raises in Postgrex (not verified). `/source/` has no plug, same likely outcome. `/host/+10` renders plant 10 with canonical `/host/10`.
- **Everything is read twice.** Mount runs on the dead and the connected render: the host page, Galls, images, range and bounds (H:42-93), the Source, Galls, images and dates (S:42-88), each twice.
- **Wording:** the Host description says "host plant species" for varieties and "with 1 associated galls" (H:57-58). The Source page labels `author` "Authors:" and the citation "Citation (MLA Form):" whatever its form (S:195, 222). Dates are "October 01, 2026" (zero-padded day, `%B %d`, UI:707-709).
- **Name sorting is case-sensitive.** `Enum.sort_by(& &1.name)` (H:180); names starting lowercase or with a bracket sort after capitals. Descending is `Enum.reverse`, so ties (all Galls of one completeness) reverse too: sorting Complete descending gives complete Galls Z→A.

## 1. Host page (`/host/:id`)

### Route, lookup, redirects, head

- **Route:** `live "/host/:id", HostLive` in the `:public` live_session (router.ex:221; on_mount `UserAuth :fetch_current_user`, `ContinentScope :default`, `TrackPageView`). The browser pipeline runs `Plugs.LegacyEntityRedirect` first (router.ex:28).
- **Old genus placeholders 301** (LER:28-43): `/host/:id` with `id` in 1..9223372036854775807 whose ID is a crosswalk `:genus_placeholder` (`Taxa.get_by_legacy_id/2`; the 159 old "Genus spp" plants) answers 301 to the genus page (`TaxonomyURL.public_path`, e.g. `/genus/Quercus`). A plug, so it is permanent (a LiveView redirect is a 302). Every other ID passes through.
- **Mount** (H:22-27): `Integer.parse(id)` must consume the whole string, else "Invalid host ID". No `handle_params`: query parameters are ignored.
- **Lookup** (`Taxa.host_page/1` → `HP.for_taxon/1`, HP:60-69): the taxon by ID (plants kept their old IDs), only when `kingdom == "Plantae"` and rank in `species subspecies variety form`; anything else (missing, a Gall's ID, a genus or family taxon) is "Host not found". Synonym names are not taxa, so there is no synonym redirect; an old ID is the same ID.
- **Head, found** (H:54-92, root.html.heex:8-32): `page_title` the accepted name (live title "Name"; og/twitter title "Name | Gallformers"); `page_description` "Name - A host plant species documented on Gallformers with N associated galls."; `page_url` (canonical and `og:url`) `/host/:id`; `page_image` the first image's full original URL (else the site default in og tags); `page_noindex: false`; `page_json_ld` `{"@context": "https://schema.org", "@type": "Thing", name, description, url: base_url <> "/host/:id", identifier: name, image (when any)}` encoded to a string, rendered by the root layout with the CSP nonce (ef2a1474). No `page_type` (og type "website").
- **Head, not found:** title "Host Not Found", description "The requested host plant was not found on Gallformers.", no canonical, no image, no JSON-LD, noindex.

### What the page shows (H:220-470)

Desktop (`lg`, 1024px and up): a five-column grid, the left two columns the header and the Galls table, the right three the range map (`flex-1`, stretching to the left column's height). Below it a two-column row: Synonymy left, Photos right (if there are no synonyms, Photos take the left cell). Then a rule, See Also, record metadata. Below `lg` everything stacks in this order: header, Galls, Range, Synonymy, Photos, See Also, metadata. No page-level h1 or title bar (`Layouts.app` gets no `page_title`).

1. **Header row** (H:232-256): `h2` (2xl bold) with the name through `taxon_name` (default rank species: binomial and infraspecific epithet italic, rank words upright), linked to `/id?h=Name` (see Findings); an admin-only pencil (`ph-pencil-simple`, h-5 w-5, `title="Edit in admin"`, `href` `/admin/taxonomy/:id`, `Accounts.admin?`); on the right the `data_complete_badge`: "Complete" (`gf-badge-success`, title "All galls known to occur on this plant have been added to the database. However, sources and images may be incomplete.") or "In Progress" (`gf-badge-warning`, title "We are still working on this species so data might be missing.").
2. **Taxonomy breadcrumb** (H:258-264): `taxonomy_breadcrumb` with family, intermediates, genus and section from `LineageBreadcrumb.from_lineage(host.lineage)` (format in `rank-pages.md` §1: bold "Family:", "Genus:" (italic) …, `|` separators, live `navigate` links by raw name). Hidden when the lineage has none of those ranks. The plant itself and any species above a variety are not shown.
3. **Abundance** (H:266): `<p><strong>Abundance:</strong> common</p>` only when the plant has one (the `abundance` table's name; 803b decision 6).
4. **Common names** (H:269-272): "**Common Name(s):** a, b" (alphabetical, comma-joined, `text-gray-700`), only when there are any.
5. **Associated Galls** (H:275-385): `h3` "Associated Galls (N)" (N = all Galls). With Galls: a bordered `gf-table gf-table-compact` with columns **Gall** (sortable, `taxon_name` of the display name `COALESCE(name_override, name)`, `href` to `/gall/:id`), **Complete** (sortable, `w-24`, centered; green check or red x), and for admins an unlabeled column of pencils to `/admin/galls/:id` (`title="Edit in admin"`). Initial order by name then ID (catalog.ex:996), re-sorted by name. 10 rows a page; the pager (only with more than 10 Galls) shows "1-10 of N", Previous (disabled on page 1), "Page X of Y", Next (disabled on the last page). Without Galls: "No galls recorded for this host." (italic). No common names, images, Host counts, or links to galls on the genus.
6. **Range** (H:389-403): `h3` "Range", then `range_map` `id="host-range-map"`, `class="flex-1"`, `in_range` (exact leaf codes), `inherited_range` (leaves of country-level rows), `introduced_range` (the introduced subset, hatched), `bounds` from `Places.get_bounds_for_codes(range ++ inherited_range)`, `navigable` (a click opens `/place/:code`). Always rendered; with no rows the hook's overlay says "No range data available". The `range_map_legend mode={:public}` (Documented, Country-level record only, Introduced range) only when there are inherited or introduced codes. No "not an occurrence map" caveat (the Gall page has one; here it is the plant's own distribution).
7. **Synonymy** (H:409-440): only when the plant has synonyms. `h3` "Synonymy (N)", a `gf-table` **Name** (`taxon_name`) / **Notes** (`sensu`, or "—"), sorted by name then sensu (HP:76-81), 10 a page with `pagination` (`synonymy_page`). Always open (d7ae2726 removed a show/hide toggle to match the Gall page).
8. **Photos** (H:443-454): only when there are images. `h3` "Photos (N)", `image_gallery` `id="host-images"`, `edit_href` `/admin/taxonomy/:id#images` (the `#images` card on the taxonomy edit page) with `current_user` (admin-only edit link), `no_image_src="/images/noimagehost.jpg"` (never reached). Images by `sort_order` then ID (images.ex:91-98); each gets `url`/`src` (CDN + original path), `small_url` ("original" → "small" in the path, unused by the gallery) and alt "Host plant image"; credit fields come from the image row (creator, license, licenselink, sourcelink, attribution, caption, uploader, lastchangedby). Gallery behavior in `domain-and-media.md` §1.
9. **See Also** (H:459, UI:612-680): `see_also type={:host}`: its own rule, "See Also:", a three-column grid of logo links (new tab, `rel="noreferrer"`): iNaturalist search, Google Scholar, Biodiversity Heritage Library, each searching "Genus epithet" from `TaxonName.parse` (qualifiers dropped; just the genus when there is no epithet), `aria-label` "Search for this species on …".
10. **Record metadata** (H:461, CC:749-768): "Created Feb 1, 2026 3:45 PM UTC • Last updated …" from the taxon's timestamps, above a rule.

No Sources block (803b decision 1: the six plant citations were dropped). Tests assert "Further Information" is absent.

### Events and hooks

- `sort` `phx-value-field` `name` | `datacomplete` (H:146-163): same field flips direction, a new field starts ascending; resets to page 1. Default name ascending. `datacomplete` ascending puts incomplete (false) first.
- `prev_page` / `next_page` (H:128-139): ±1, clamped.
- `synonymy_page` `%{page: n}` from `pagination`'s `JS.push` (H:165-170): clamped to 1..total.
- `gallery_index_changed` (H:141-144): no-op, answering the ImageGallery hook's push.
- `navigate_to_place` `%{code}` (H:172-175): from the RangeMap hook's click; `push_navigate` to `/place/:code`.
- Hooks: ImageGallery on `#host-images`, RangeMap on `#host-range-map` (both `phx-update="ignore"`). No search, no debounce, no URL state. Links: Gall rows, the ID-tool heading and admin links are `href` (full load); breadcrumb links `navigate`.

### Read models

- `Taxa.host_page/1` → `%HostPage{id, name (accepted), rank, lineage ([%{taxon_id, name, rank}] root first, the taxon included), synonyms ([%{name, sensu}] by name), common_names ([String] alphabetical), datacomplete, abundance (name or nil), inserted_at, updated_at}` or `:not_found` (HP:29-94).
- `Catalog.list_galls_for_hosts([id])` → `[%{id, name, datacomplete}]`, each Gall once, by name then ID (catalog.ex:941-998).
- `Images.list_images_for_taxon(id)` → `Image` structs with `source` preloaded, by `sort_order`, ID.
- `Ranges.get_display_range_for_taxa([id])` → `%DisplayRange{in_range, inherited_range, introduced_range}` (leaf codes; country-level rows expanded; exact native rows override an introduced country; ranges.ex:259-326).
- `Places.get_bounds_for_codes(codes)` → the server bounds the map frames first.

## 2. Source page (`/source/:id`)

### Route, lookup, head

- **Route:** `live "/source/:id", SourceLive`, `:public` live_session (router.ex:224). No plug redirects. Inbound links: Gall page Source cards and modal (gall_live.ex:668, 822), home "Recently changed" (`home_live.ex:284`), admin images (`images_component.ex:376`), admin Source editor's public link (`source_live/edit.ex:250`), the sitemap (every Source, monthly, 0.5).
- **Mount** (S:22-40): `Integer.parse(id)` whole string, else "Invalid source ID". `Sources.get_source/1` (`Repo.get`) nil → "Source not found". No `handle_params`. Retracted Sources load like any other.
- **Head, found** (S:57-86): `page_title` the Source title; `page_description` "Title by Author - A source referenced on Gallformers." (" by Author" only when `author` is set); `page_url` `/source/:id`; `page_image` the first image's full URL; `page_json_ld: nil`; `page_noindex: false`.
- **Head, not found:** title "Source Not Found", description "The requested source was not found on Gallformers.", noindex.

### What the page shows (S:145-305)

Desktop: a full-width header, then a three-column grid (details two thirds, images one third), then Connected Galls, "What this Source says", metadata, each full width. Below `lg` the images drop under the details; below `md` the details' two-column grid becomes one.

1. **Header** (S:155-187): `h1` (2xl bold maroon) the title, plain text (no `taxon_name`, so Latin names in titles are upright); admin pencil to `/admin/sources/:id` (`title="Edit in admin"`); `data_complete_badge`: "Complete" (title "This source has been comprehensively reviewed and all relevant information entered.") or "In Progress" ("We are still working on this source so information from the source is potentially still missing."). Then `source_dates id="source-dates"` (UI:715-760, small muted): "Added to Gallformers October 01, 2026 · updated November 02, 2026" (the update left out when on the same day), "From the original Gallformers data" (· updated … when a package came later) for a Source from the old data, or nothing when its first package isn't applied. Then `source.link` as its own URL text, new tab (`noopener noreferrer`, `break-all`), only when `valid_url?` (http/https with a host; helpers.ex:53-67).
2. **Details** (S:193-217): "Authors:" `author` or "Not specified"; "License:" linked (new tab) to `licenselink` when valid, text `license` or "View", else `license` or "Not specified"; "Publication Year:" `pubyear` or "Not specified". Labels semibold gray-700.
3. **Citation** (S:220-225): "Citation (MLA Form):" and the citation in italics, only when set.
4. **Images** (S:229-231): `image_gallery id="source-images"`, no `edit_href` or `current_user` (no admin links), no `no_image_src` ("No images available" box when empty). Images of any Gall or plant with this `source_id`, by the owner's name then ID; alt "Image from source"; credit fields as on the Host page.
5. **Connected Galls** (S:235-273): `h2` "Connected Galls (N)"; a one-column `gf-table` "Gall", each row `taxon_name` linked (`href`) to `/gall/:id?source=:source_id` (so the Gall page opens this Source's card in its modal, gall_live.ex:58-66; when the Gall page doesn't list this Source, e.g. a Source that only attributes Facts and isn't the lead, the parameter is silently ignored). 20 a page, `pagination` ("Showing 1 to 20 of N results", Previous, "Page X of Y", Next) only with more than one page. Empty: "No galls connected to this source." (italic muted). The Galls are those it cites (legacy citations), those its **current** Facts are about (any gall Fact kind, either end of a Relationship, the Galls of a qualified Relationship), and, for the Gallformers Source, those with a note of it; each once, by name then ID.
6. **What this Source says** (S:276-292; matter f14c): `section id="source-facts"`, `h2` "What this Source says", the line "The Facts Gallformers holds from this Source, by Gall, each with the Source's own words." Before the connected mount: spinner + "Loading…". No Facts: "No Facts from this Source yet." (italic). Otherwise `facts_view id="source-facts-galls" mode={:public}` (FC:236-430):
   - One `gf-card` `section` per Gall with Facts (`data-role="facts-gall"`, id `source-facts-galls-gall-<id>`), by name. Header `h3` the Gall's `taxon_name`, `navigate` to `/gall/:id`; "The Source: “…”" when the Source named it differently.
   - Categories in order Inducer, Hosts, Traits, Range, Descriptions, Aliases, Other, each an `h4` with its count (`data-category`), in two CSS columns on `lg`. Traits are grouped by trait name (humanized) in a label/values grid. "No Facts." when a Gall has none left.
   - Each Fact a row (`li id="fact-<key>"`, `data-status`): the standing mark when not current; "not" for a denial; the value in Gallformers' terms (Inducer/Host taxon with rank above species, other Relationship types with their label, Trait value or "suggested: …", "in"/"not in"/"only in"/"recorded in" + place, alias name + kind, description quote clamped to two lines, qualifier "kind: value"); the Source's differing words muted ("“…” · “…”", title "The Source's words"); "The Source: <statement text>" when given; a "Quote"/"N quotes" button toggling the quotes client-side (`JS.toggle_class`, `aria-controls`), each quote a `review_quote` with "p. N". No edit menu, no review links, no "new" marks, no passage loading (`on_passage` nil).
7. **Record metadata** (S:294): the Source row's timestamps.

Not shown: kind, structured authors, authored date, DOI, URL, ISBN, normalized license, retraction and its notice Source, documents (full text, notes as documents), taxonomic Facts, Galls with only non-current Facts.

### Events and hooks

- `page` `%{page: n}` from `pagination` (S:98-102): clamped to 1..total.
- `gallery_index_changed` (S:104-107): no-op.
- Client-only: the quotes toggles in `facts_view`. Hook: ImageGallery on `#source-images` (only with images). No search, sort or URL state.

### Read models

- `Sources.get_source/1` → the `Source` struct (all columns; the page reads `title author pubyear link citation datacomplete license licenselink inserted_at updated_at`).
- `Import.source_dates([id])` → `%{id => %{ingested, updated, legacy?}}` (`Gallformers.Import.SourceDates`: ingested = first applied batch; updated = latest applied batch, later attribution change or Source edit; legacy = no package brought it), `Map.fetch!`ed.
- `Catalog.list_galls_for_source(id)` → `[%{id, name, datacomplete}]` (datacomplete unused), by name then ID.
- `Images.list_images_for_source(id)` → `Image` structs, by owner name then ID.
- `Import.facts_for_source(id)` (connected only) → `FactsView.group/2` output: `[%{key, gall_id, name, name_as_written, status: :resolved, facts: %{category => [entry] | %{trait => [entry]}}}]`, entries with `fact_id`, `kind`, `category`, `standing`, `stance`, `value`, `words` (`evidence` quotes with page, `names`, `term`, `value_as_written`, `statement_text`), `batch_id`, `ref` (import.ex:2071-2121).

## Hard-won lessons

1. Empty strings are truthy: `if @source.link` rendered `href=""`, which reloads the page (cd52132b); malformed URLs made `<.link>` crash, so links render only through `valid_url?` (http/https with a host), and bad rows were fixed by migration (d9b244fa).
2. A LiveView redirect is a 302; permanent redirects for dead URLs live in a plug (`LegacyEntityRedirect`, 67378c93), bounded to bigint IDs because a larger number would not encode.
3. Genus placeholder "plants" ("Quercus spp", 41ad2d39) became the genus taxon as Host; their `/host/:id` 301s to the genus page and their Galls live there, not on species pages (803b).
4. Host pages keep the old plant IDs, so old links still work; higher taxa IDs are new and not Host pages (803b Task 5).
5. JSON-LD is passed as an encoded string and rendered by the root layout, which has the CSP nonce (ef2a1474).
6. Common names are not synonyms: shown first as a list, scientific synonyms in their own table with sensu notes (9be620ba); the table is always open, as on the Gall page (d7ae2726).
7. Plant Sources were dropped (only six citations; 803b decision 1) and the Host page's Sources block, ID Notes banner, modal and `?source=` with them. Plant `datacomplete` and abundance were carried over as editorial fields so the badge and Abundance line stay (decision 6).
8. Source page Gall links carry `?source=` so the Gall page opens that Source's text (e3010f6f).
9. The Facts are read on the connected mount only, so the first render, which crawlers read, has the Source and its Galls without waiting (7a701a71, f14c). One Facts component serves the review preview, the admin and the public page; the public mode must show no edits, review links or "new" marks.
10. Source dates are derived, never typed; a Source from the old data shows "From the original Gallformers data" instead of a date (f14c, `SourceDates`).
11. Admin links point at the new admin (taxonomy admin, `/admin/galls/:id`, `/admin/sources/:id`) and show for `Accounts.admin?` only, no longer behind the legacy-admin switch (a075e07a); tests refute the old `/admin/gallhost` and `/admin/images` links.
12. `taxon_name` renders a name's italic and upright parts as separate elements, so name-order assertions use the page's text, not raw HTML (host_live_test, uncommitted).
