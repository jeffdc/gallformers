### Natural Earth quirks discovered

- **French overseas departments** (GUF, GLP, MTQ): NOT in `admin_0_countries`. Found in `admin_0_map_subunits` under France (ADM0_A3=FRA, SU_A3=GUF/GLP/MTQ). ISO_A2 values are departmental codes (FR-973, etc.), not the alpha-2 codes we need.
- **Caribbean Netherlands** (BES): NOT in admin_0_countries OR map_subunits. Islands (Bonaire=NL-BQ1, Saba=NL-BQ2) are NLD subdivisions in admin_1. Sint Eustatius (NL-BQ3) may not exist in NE 10m.
- **tippecanoe-decode output format**: Outputs nested FeatureCollections — outer features are per-layer wrappers, inner features are the actual geometries. Empty tiles return empty string (not valid JSON).
- **Shapefile field names**: Case-insensitive in DBF format. Fields from different source shapefiles get mapped by name when using `ogr2ogr -append`.
- **macOS bash**: Ships with bash 3.2 — no associative arrays (`declare -A`). Use parallel arrays instead.
