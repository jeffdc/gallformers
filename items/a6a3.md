## The notes

Each Gall's Gallformers ID note (Source "Gallformers ID Notes", Source 58; ~400 characters on average, no dates) was migrated verbatim by the catalog migration (`CatalogMigration.Notes`) as one undated `:note` document of the Gallformers Source (`Sources.store_note/5`; text in the private bucket, one document item holding all of it). Nothing has been extracted. Numbers: 1,299 notes in the dev data (775 on undescribed Galls, 524 on described); ~257k and ~262k characters of text. 1,557 undescribed Galls, only ~781 with a note; together 11,010 legacy Traits and 2,067 legacy Hosts with no other Source.

What notes hold (decided by Adam and Jeff, 2026-10-17): no look-alikes concept (inherent in a matching set of Traits). Gallformers' statements of Fact: Hosts added from iNat Observations, "tentative" ones included (the single Observation is their evidence); descriptions of undescribed Galls; where and when a Gall was seen (recorded occurrences, the `occurrence` Fact kind); adjudications of conflicts between Sources, with a reason. Commentary that isn't a Fact (summaries of the literature and the state of knowledge, open hypotheses, pointers to people and resources) stays as page content. Passages copied from published papers belong to that paper as a Source. Recorded in `docs/import/producer-guide-background.md`, "Gallformers ID Notes".

Timing (Jeff, 2026-10-28): all of the notes, undescribed and described, are processed before the public release, on preview with the rest of the backscan; decisions carry over through the replay log.

## 20e5's plan ("Current thinking, consolidated", 2026-11-06)

- **What a note is:** each Gall's note is Gallformers' document for that Gall, shown whole on the Gall page ("Notes on ID and Taxonomy"). Facts are drawn from it where it states them; commentary stays text.
- **Undescribed Galls (775 notes):** their Facts come from the current data, already credited to the Gallformers Source by the catalog migration (`CatalogMigration.UndescribedGalls`: every legacy Fact of an undescribed Gall confirmed as Gallformers', dated the run's day, at cutover the cutover date, legacy attribution kept), dated about now. The notes stay as text, with no LLM extraction. Open: question d8c6.
- **Described Galls (524 notes):** code writes the patterned statements: "<plant> added (tentatively) as a host based on [observation]" (157) as Host Facts with the observation as evidence; "observed in <place> in <month>" (109) as occurrence Facts, place matched to our places (the month is when it was seen, not a season Fact: extraction keeps the two apart). Notes with taxonomy or ruling sentences (~200) need judgement: question dd84. Comparisons, references (Joyce Gross' gall types, links), remarks on the inducer and the state of knowledge stay text.
- **If the LLM is used:** chunk ~50-100 notes per run, one text block per note, each Gall declared by its Gallformers ID (a contract change: today a note package quotes one note and one Gall). Each chunk costs about a paper (~$8-12, estimate); all 524 described ≈ $60-90, against $700-1,700 one note at a time (the 2026-10-30 trial: 10 notes through phases 3-6 for $12.83, about $1.28 a note; all validated, one finding disputed). Each group as a single Source fails: the output (thousands of Facts) overwhelms one session. Run one trial chunk (~50 notes, ~$6-10) before the rest.
- **Taxonomic remarks** (synonymy opinions, "treated as", suggested name changes) stay text: Gallformers is a taxonomic authority only as a rare exception (Jeff, 2026-11-06), so a remark's position comes in through the paper it rests on, in the backscan.
- **Splitting notes apart:** separate the Fact-bearing statements from the commentary, so the note text that remains is the ID guidance and commentary (Jeff's "split apart"); how the remaining text is stored and edited is part of the curation design.
- **Dates and conflicts:** note Facts are dated about now (the exact date is unimportant; it settles to about when the work is done, the cutover-date rule). A note Fact that would supersede or withdraw a Fact from the literature goes to a curator ("option c"), except a recorded occurrence outside the Gall's range, which is added automatically and the range updates. Conflicts come only from Traits with one value, range adjustments for the same place, and explicit denials; Hosts add up. If there are hundreds, consider dating by kind (single-value Traits stay behind the literature until a curator confirms). Options rejected: (a) import last, dated now (notes win, hurts where a note is out of date); (b) import first, undated (literature wins until a curator edits the note); (e) real dates from the note or its Observations (covers only part).
- **Range:** a Gall's range can widen as long as it stays within the union of its Hosts' ranges; beyond that a Host's range must be expanded (common with cultivated plants).
- **The pattern analysis** (2026-11-05, scratch script `notes_patterns.py`, not in the repo): of undescribed notes, 255 fully handled by code, 408 partly, 112 not, 160 with a taxonomy or ruling sentence; of described, 124 / 227 / 173, 206 with one. Sentences: undescribed 545 "observed in", 398 descriptions, 20 Hosts added, 209 taxonomy/ruling, 1,045 unlabelled; described 157 Hosts added, 109 "observed in", 359 taxonomy/ruling, 1,120 unlabelled. The patterns are crude (they miss e.g. "Rhus aromatica is confirmed as a host based on Russo 2021"), so the code share would rise with work.

What's built for the notes pipeline (in the code as of a0434bcf): a Gallformers batch can carry `source.note` (`gallformers_gall_id`, `stated_on`) and `source.document`, quoting the note as one text item (`#/texts/0`); on import the quoted text is stored as that Gall's note version unless Gallformers holds it already (`Sources.store_note/5`, idempotent), and each attribution takes the note's date with what it quotes as its statement text (`Import.Attributions.with_note/2`). `GALLFORMERS_STATEMENTS.md` has "Reading a Gall's note"; example `priv/import/examples/gallformers-note/`. Generator: `mix gallformers.import.notes --dir DIR [--undescribed|--described] [--limit N] [--stated-on DATE] [ids]` (`Import.NotePackage`), then `produce note <dirs>` in `services/import-producer`. A note batch's Gall is resolved by the note's ID (the trial found guessed matches and a proposed duplicate Gall). The Gall page's Editor saves a note through `Sources.store_note/5`.

## What d3b0 decided later, that conflicts

- **ID notes are 100% editorial** (Jeff, 2026-11-07): editorial prose, nothing to do with Facts. 20e5 treats a note as Gallformers' *document* that Facts are extracted from, with quotes pointing at it, and (2026-10-24) "a curator edits the note and the edit is re-extracted".
- **Notes leave the Gallformers Source** as editorial records on the Gall (d3b0 "Consequences to build"; the storage move is planned under item bc85). Today they are `:note` documents of the Gallformers Source, and the built note-package contract quotes them as that Source's document.
- **Old ID notes are processed into changes carrying the notes' own dates.** A change is a package of the one Gallformers Source: small, timestamped, audited; the old site's data is its undated base. 20e5 dates note Facts "about now". Note the tension to resolve: 20e5 and the migration say the legacy notes have no date.
- **Note saves aren't replay-logged** (d3b0's audit: `Sources.store_note` is audited but not replay-logged; a cutover risk). Closing that gap is in bc85's plan; the notes build must not add unlogged writes.
- Also from d3b0: the legacy-data Source merges into the Gallformers Source as its undated base ("legacy-only" becomes "only Gallformers' undated base", shown as unconfirmed), which touches how `UndescribedGalls` credits undescribed Galls; restating a Fact carries the earlier statement's evidence forward (the wiped-note-quote bug).
- Distinct from ID notes: a note on a Fact ("Add a note…" in the Fact inspector; `fact_notes`, editorial, applied at once) is already its own record.
