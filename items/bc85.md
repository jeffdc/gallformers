Plan the One write path phase as one-session tasks for Jeff to approve as items. This item writes the plan, not the code. Each task says what it deletes ("Deletes:") and the functions it calls ("Calls:"). The phase doc (9a53) holds the rules; the plan must cover everything in its "What this phase builds", which is, in order of dependency as you judge it:

**First:** the phase *Design: is all data a Fact?* (de5a, item d178) settles whether all data is tied to Facts. This plan starts from its decision.

1. **The inventory of every write path.** For every kind of data (each Fact kind, plants and their ranges, a Gall's editorial fields and name parts, ID notes, images, keys, articles, Source records, users), every function that writes it today, and who calls it (screens, import, migration, replay, mix tasks). Start from /Users/jeff/dev/gallformers/docs/plans/2026-11-12-history-audit/state/2-editing.md (seven editing surfaces; a Gall's Host written five ways, a plant's range five, a plant's name four) and state/6-migration-via-import.md (the migration's own SQL for Host ranges, WCVP links, images, keys and generation-group links). The inventory is the plan's foundation: show it to Jeff before the tasks.
2. **One writer and one reader per kind**, with every caller moved onto it and the copies deleted (retirements test first).
3. **The UI phase's stubbed interfaces** (phase 08c1, item 2e6f), filled in on those writers.
4. **Every Fact write through a package:** retire "Based on which Source?" (BasisPicker, used by TaxonomyLive.Edit, Index, New, TaxonChanges, SpeciesLive, SpeciesLive.Editor; and Import.TaxonomyStatements); SynonymDecisions.carry_out's tree edits become the reviewed Source's statements; Source corrections (SourceCorrections.correct/6 kept only as long as replay needs it), merge and rename aliases (Catalog.Records.add_former_label, Catalog.GallRenames), split answers (Catalog.repoint_inducer/4), term moves and placements outside apply (Catalog.move_term_attributions/5, Import.place_term/4, Import.VocabEdits); Import.InatTaxa's recording.
5. **Packages apply all or nothing** (Jeff, 2026-11-15; today each batch commits on its own, import.ex about 2928-2993).
6. **Gallformers changes timestamped** (attributions.stated_on is a date today); restating a Fact keeps its earlier evidence (Facts.attribute/2 replaces it today).
7. **Two Gallformers Sources kept separate** (Jeff, 2026-11-14): Gallformers legacy data (Sources.get_legacy_data_source/0) undated, and Gallformers dated. Check every reader that treats them as one (Sources.own_source_ids/0, Import.GallFacts.for_gall/1) does so on purpose.
8. **ID notes out of the Gallformers Source** into an editorial field on the Gall (today undated :note documents of Source 58, CatalogMigration.Notes, Sources.store_note/5). What happens to the old notes' content is phase e090's.
9. **History views from packages** (the Gallformers Source page's changes, a Fact's history; Import.fact_history/1 reads the audit trail today).
10. **Remove attributions.cited_source_id / cites_as_written** (Import.Attributions cites/1, Import.SourceCorrections, Facts.attribute/2); decide with Jeff whether Facts.Evidence's cites_as_written (a quote's cited work, read by Curation.Statements and Curation.TaxonomicReading) is in scope.
11. **One name and authorship comparison** on every path (TaxonomyLive.TaxonChanges.name/5 compares raw strings; Import.TaxonomyQueue uses NameNormalizer.normalize_authorship/1). Failing test first.
12. **The audit layer complete:** item c350 (the Source records) and Host ranges tracked; every write names its actor; the cause of the 2026-11-07 audit-conflict crash (backlog bug 0162).
13. **Replay made mechanical:** replace the 22 per-kind replay pieces (Import.Replay, Import.ReplayEntry kinds) with re-applying the same writes in order through the one writers, covering what they miss today (Gall editorial fields and name parts, ID notes, photos, content pages).

Done when Jeff has approved the inventory and a task list covering 1-13 as items.
