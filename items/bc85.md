## The model the plan builds (Jeff, 2026-11-07)

- **Any Source may state any Fact.** The literature is the usual authority; Gallformers may state any Fact, taxonomic included, as an exception.
- **New Facts come in exactly two ways:** ingest a Source to approval, or edit/add a Fact on a Fact-bearing entity. **An edit is the ingestion of a Gallformers statement**, resolving to the same changes through the exact same code path as a Source ingestion. There is no second code path that creates Facts.
- **Sources never reference each other formally.** A curator may write "Weld (1959)" in a statement's text; it stays text.
- **Review edits and corrections are under the Source's authority.** Edits during review correct import errors or map what the original couldn't be read for; every review action states Facts *from the Source*, not from Gallformers or the curator (who is in the audit). Review decisions that change the non-plant tree become that Source's statements in its package. Correcting an ingestion mistake is the same act as review, lower ceremony: the corrected Fact overrides the incorrect one with the original Source's authority, audited (who, why, when).
- **Split and lump are taxonomic acts, so Facts,** under the authority of the Source whose statement decides them.
- **Delete** is only for data added by mistake: a true exception outside the rules.
- **A change is a package, not a Source.** There is one Gallformers Source (one search result, one Source page). A change is a package of it: small, timestamped, audited (who). The old site's data is its undated base (so the literature outranks it and the backscan can correct it); each old ID note processed is a change with the note's date. A newer package from the same Source replaces its earlier statement (a Source's newer word supersedes its own); recency between Sources is unchanged. History lives in the packages (batch files and `batch_statements` per Fact), so "what Gallformers said about this Fact over time" and "what this change did" are queries. The same model covers every Source: a first ingestion, a corrected re-ingestion, an author's update, review corrections and Gallformers changes are all packages of a Source through one code path. The one Gallformers-specific rule: its statements take their change's timestamp, not a single authored date.
- Accepted trade-off: earlier Gallformers positions on a Fact are history one click away, not separate voices.
- Rejected: a Source record per change (thousands of tiny Sources would swamp search and Source views without condensing code); one Source with several statements per Fact (wide change); replace-only with history only in the audit.
