## Analysis: production API traffic (2026-11-16)

Source: production's request log, /data/logs/app.log and its 20 rotated archives, 2026-10-11 to 2026-11-16 (about 1.95M requests). The copies were analysed locally and then deleted. Request entries are .request.connection.{path,status,method} and .request.client.{ip,user_agent}, not .conn (bug 56b4). The window covers only what fits in 1 GB of logs, so a caller that runs less than monthly may be missed.

About 24,500 non-404 calls to /api/v2 in five weeks; daily volume runs from a few dozen to over 4,000.

Callers, by kind (identities and contact details deliberately left out of mull):
- A research data pipeline (R httr2), one address: 8,218 calls over two days (Nov 4-5), crawling every /galls/:id and /galls/:id/sources.
- A personal gall-monitor script, one address: about 300 calls, roughly weekly (Oct 14, 21, 28, Nov 15): /galls, /galls/:id, /galls/:id/images, /hosts/:id/galls.
- A plant app building a knowledge base, one address: 292 calls on Nov 12: /hosts/:id/galls, /places, /hosts, /stats, and 5 calls to /families, /genera, /sections.
- A dataset-discovery bot: 3 calls (/stats, /hosts, /hosts/:id/galls).
- Our own post-deploy smoke test (Req from GitHub Actions): about 30 calls.
- A cluster of networks in China: about 15,000 non-404 API calls, every day, with a new invented user agent on almost every burst ("research", "line4-verification (academic species-name audit)", "generation-naming-check", python-requests, curl, placeholder example.com contacts), guessed paths (/api/galls, /api/v2/genera/Callirhytis) and short purposeful bursts. It looks like AI agents running in a provider's sandbox and researching galls for their users, not one scraper. The same networks made about 115,000 HTML requests, six times their API traffic, so disabling the API would not keep them from the data.
- A cloud crawler with a Chrome user agent (Google Cloud addresses): about 270 calls since Nov 7, all /galls/:id.
- User agents claiming to be AI or search bots (kimi, qwen, deepseek, claudebot, ...) on /api are vulnerability scanners probing for .env files; all 404.

What the callers use:
- Real callers use /galls/:id, /galls/:id/sources, /galls/:id/images and /hosts/:id/galls. Gall and host IDs are unchanged on taxogall, but the meaning of places (empty now means "anywhere"), sources and aliases changes, so they would silently get different data under the same path.
- The taxonomy endpoints, whose IDs are new on taxogall, are barely used outside the agent cluster: the plant app's 5 list calls, our smoke test, one browser, one social-media crawler. The agent cluster mostly gets 500s from /genera (bug f71d, about daily).
- The rate limit (100/min per address) rarely fires (27 times in three days); the agent cluster's traffic is spread over about 170 addresses.

Conclusion (decision 03d0): keep the API, move it to /api/v3 at 3.0.0, and return 410 on /api/v2 at release, so the changed meaning breaks loudly. Jeff contacts the users he can identify.
