**What:** delete the import review's dead code (the 2026-11-09 audit's finding D), with its tests if any (none reference the settle flow), and stop `Review.dry_run` crashing on an error. `mix precommit` passing is the proof that nothing used the deleted code. This goes first in the phase: it's a day or less and shrinks what the rest of the cleanup touches.

**Why the settle code is dead.** In his walk-through of package 115 (2026-11-08) Jeff decided that a Source is authoritative for what it says: every statement goes in credited to it, including ones that disagree with what we have. The review asks only what Gallformers can't tell (which plant, Gall or term) and what the pipeline's AIs disputed. So a candidate Gall is always one click: its comparison (a sentence plus "Compare") is evidence for the identity call, not statements to settle. `Questions` no longer makes a disagreeing candidate a `:statements` follow-up; leaving out one statement is done with the last step's Facts edits (Drop / Change Host). That left the settle follow-up unused by any page. Jeff's decision 5 (2026-11-09): dead code goes.

**The dry run.** `ReviewLive.Review`'s `preview/1` runs `dry_run/2` over every package awaiting review in a `start_async`, and `dry_run/2` does `{:ok, preview} = Import.preview_package(package, actor)`, so an `{:error, _}` crashes the task (about review.ex:333-349). Use the Facts page's error handling: `ReviewLive.Facts.load_facts/2` (`review_live/facts.ex`, about 113-132) runs `Import.preview_package/2` per package, returns the first `{:error, _}` it finds, and otherwise merges the previews into one. Keep the Facts page's code. Item a81c (retire the step and Facts pages) moves that dry run into the review's last step and deletes the Facts page.

**Tests first:** write a failing test for the dry run's error case and watch it fail before fixing it. The deletions need no new tests: precommit is the check.

**Done when:** everything listed above is gone and the dry run handles an error without crashing. `mix precommit` is clean, and the dev compile with `--warnings-as-errors` is too. If the duplicate-code test (`test/gallformers/guardrails/duplicate_code_test.exs`) reports fewer findings than its baseline allows, lower the baseline with `mix gallformers.guardrails.baseline` (it runs in test).
