On 2026-11-05 the design-system inventories found five bugs: `docs/design-system/inventory/actions-and-feedback.md`, `forms.md` and `domain-and-media.md`. 2c8c logged them as production bugs. Each, with where it stands in code as of a0434bcf (code read, not checked in a browser):

1. **`put_flash(:warning, …)` never renders.** `flash_group` renders only `:info` and `:error`.
   - taxogall: gone. Nothing calls `put_flash(:warning`; the admin Gall edit page that did was deleted.
   - main: still there, on "deleted by another user" messages:
     - `lib/gallformers_web/live/admin/gall_live/form.ex:743`;
     - `host_live/form.ex:1321` and `:1338`.
2. **A component-scoped flash's auto-dismiss is never cleared on the server.**
   - The bug, in `lib/gallformers_web/live/admin/images_component.ex` (about lines 96–104): the info flash has `auto_dismiss={5000}` and `phx-target={@myself}`. The AutoDismiss hook (`assets/js/hooks/auto_dismiss.js`) sends `lv:clear-flash` with `pushEvent`, which goes to the parent LiveView, not the component. So the flash hides in the browser but stays in the component's flash, and `phx-target` only steers the click.
   - taxogall: still present.
   - main: not affected; its images component sets no `auto_dismiss`.
3. **`text-error` is undefined.** The `.input` error text used `text-error` (and wrapper classes `fieldset` / `label`), DaisyUI leftovers that nothing in `assets/css` defines. So field error text was probably not red, only the icon.
   - taxogall: gone; `input` was restyled onto tokens.
   - main: still there (`core_components.ex:410`, no definition in `assets/css`).
4. **Place names probably rendered in italics.**
   - The bug: the places browse tree builds leaves with `rank: nil` (main `lib/gallformers/places.ex:493`; taxogall `:592`). `TreeComponents` then calls `taxon_name` with its default rank `"species"` (main `tree_components.ex:120`).
   - taxogall: gone. `TreeComponents` was retired and `/places` renders place names as plain text (`PlacesBrowseLive`). `get_places_tree/0` still sets `rank: nil`, harmlessly.
   - main: still there.
5. **The Vocabulary page has two h1s.** `vocabulary_live.ex` rendered `<.header>` while also passing `page_title` to the admin layout, so two h1s read "Vocabulary".
   - taxogall: gone; the page is on `page_header`.
   - main: the page doesn't exist.

So the one left on taxogall is #2. On main, #1, #3 and #4 remain. 2c8c's rule for production bugs: each gets its own small fix branch off main (Jeff pushes and opens the PR), and the same fix goes onto taxogall when it applies there.

Checked on main and taxogall at a0434bcf, by reading the code only.
