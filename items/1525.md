**The problem (from `b5bd`, dev cutover rehearsal, 2026-11-07).** "Preview likely holds a bogus species 'Stephanomeria' under the genus Stephanomeria (the WCVP rank bug, from the Nastasi & Davis review); fold it into the genus." Nobody has checked whether preview holds it. Matter f465 (last updated 2026-10-23) says preview has no Postgres of its own, so it is also unclear whether preview has had any review data at all (phase f709).

**What the code and the local data say (checked 2026-11-11, as of a0434bcf):**
- *Stephanomeria* is **not v1 data**. No old `species` row is named "Stephanomeria". The bogus taxon came from the import review. A Host decision added the plant from WCVP record 3134307, which WCVP holds at rank Genus. The old code guessed the rank from the name, so it made a species "Stephanomeria" under a new genus of the same name.
- The bug is fixed in `8fa64e12` (merged as `51a90d6a`, "Add a plant from WCVP at the record's own rank"). The rank now comes from WCVP's `taxon_rank` (`Ranges.Wcvp.rank/1`), a genus goes under its family, and reuse matches at that rank. Its message says: "Logs made with the old bug replay to the genus without creating the bogus species."
- On `gallformers_taxogall` the bogus taxon is 88146 (species, origin `powo`, created 2026-11-07, under genus 88145). The replay log there has the entries that made it: `plant_added` with key `{"name": "Stephanomeria", "rank": "species"}`, and the `queue_decision` for package `680-nastasi-davis-2022-v5`, statement `t18` (`unresolved_host`).
- Curated files in `priv/catalog_migration/` fix **v1 data** the migration reads. A taxon created by a review decision is not in v1 data. It reaches production only through preview's replay log, and per the commit above that log now replays to the genus.

**What to do.**
1. Decide whether any fix belongs in a curated file. The facts above suggest it does not, but check: does replaying a log with the old-bug entries really create no species? Test it, or confirm an existing replay test covers it.
2. Fold the bogus species into its genus wherever it exists: on preview once it has data, and on `gallformers_taxogall` if that copy is still used. Any Galls hosted on it should end on the genus. Use the editorial merge or the taxonomy admin, so that on preview the change is in the replay log.
3. Find others like it. Run the query in item a7cd's notes ("accepted plant names at species rank or below with no space, or equal to their parent's name, then check each linked `wcvp_id`'s `taxon_rank`") on preview and on any other copy that has had review decisions. On `gallformers_taxogall` it returns *Stephanomeria* (88146) plus the seven one-word v1 plants (Justicia, Myrceugenia, Bersama, Tiliacora, Neoboutonia, Malacantha, Echinops). Those seven are v1 data and item a7cd's. Anything else it finds that came from a review decision is folded like Stephanomeria.

**Done when** the query returns no review-created one-word species on preview (or on the copy the backscan runs on), *Stephanomeria* is only a genus there, and it is settled, with a test, that replaying preview's log at cutover creates no such species on production.
