On main, the admin Sources list crashes whenever a species–Source link is created or updated while someone has the list open.
- **Where:** `lib/gallformers_web/live/admin/source_live/index.ex`, on main.
- **Why it crashes:**
  - The page subscribes to the `"sources"` PubSub topic (`Sources.subscribe()` on connected mount).
  - `Sources.create_species_source/1` and `update_species_source/2` (main `lib/gallformers/sources.ex`, about lines 295 and 315) broadcast `{:species_source_created | :species_source_updated, _}` on that topic.
  - The page's only `handle_info/2` matches `{event, _source}` when `event in [:source_created, :source_updated, :source_deleted]`, so either species-source event raises `FunctionClauseError` in every open Sources list.
- **Also seen as:** a timing-dependent failure of `SourceLive.FormTest` "index view requires the exact source title before deletion" (main `test/gallformers_web/live/admin/source_live/form_test.exs:109`), when another test creates a species–Source link in parallel.
- **Fix:** handle (or ignore) the species-source events in the index page, with a test.
- **Where the fix goes:** 2c8c's rule for production bugs is a small fix branch off main (Jeff pushes and opens the PR), the same fix going onto taxogall when it applies. Here it doesn't: taxogall's Sources page doesn't subscribe.

Found 2026-10-27.

source_live/index.ex handle_info matches only :source_created/updated/deleted; Sources.create/update_species_source broadcast on the same topic. taxogall's Sources page doesn't subscribe, so it isn't affected.
