Every page's canonical URL is emitted as `<meta name="canonical" content=…>`. Search engines ignore that form; it must be `<link rel="canonical" href=…>`.
- **Where:** `SEO.meta_tags/1` in `lib/gallformers_web/components/seo.ex`, line 48 on both main and taxogall (as of a0434bcf): `<meta :if={@canonical} name="canonical" content={build_url(@canonical)} />`.
- **How it's fed:** the root layout (`root.html.heex`) passes `canonical={assigns[:page_url]}`.
- **Scope:** site-wide, so every page that sets `page_url` is affected.
- **Who found it:** the Host and Source page inventory (`docs/design-system/inventory/host-and-source-pages.md`, "Findings").

It's in production, so by 2c8c's rule for production bugs it gets its own small fix branch off main (Jeff pushes and opens the PR), and the same fix goes onto taxogall.

Not listed as open in 2c8c.
