**What b016 is.** Matter b016 ("Test suite alignment to testing philosophy") tracks bringing every test file in line with `docs/testing-philosophy.md`, the standard all test work is judged against. Its core beliefs: green means deployable; test behaviour, not implementation; needing a mock is a design smell; every layer earns its own tests; TDD; tests create their own world; boundary validation is not optional. Its tiers: 1 unit, 2 integration, 3 e2e browser, 4 auxiliary, 5 post-deploy smoke.

b016 keeps two lists, **Done** and **Remaining**. A test file in neither list hasn't been evaluated, which is how files new agents create get caught. A file passes when it:
- runs `async: true` where it can, the exceptions being GenServer, persistent-term or site-wide PubSub tests;
- creates its own data, with no dependence on seed rows;
- covers the happy path, error paths and boundaries;
- asserts strongly (for a save, verify the database after it).

**Why it needs redoing.** The inventory was made in March–April 2026 against the old back end (`species`, `Galls`, `Plants`, `Taxonomy`, the old admin screens). The Tier 1 context files were all evaluated then (762 tests). On taxogall the suite is a different one: 358 `*_test.exs` files as of a0434bcf, against 54 files named in b016. **16 of b016's named files no longer exist on taxogall:**
- `test/gallformers/`: `gall_hosts_test.exs`, `galls_test.exs`, `hosts_test.exs`, `images/audit_cache_test.exs`, `plants_test.exs`, `request_logger_test.exs`, `species_test.exs`, `storage_test.exs`;
- `test/gallformers_web/components/tree_components_test.exs`;
- `test/gallformers_web/live/admin/`: `deferred_changes_test.exs`, `gall_host_live_test.exs`, `gall_range_live_test.exs`, `host_live/form_test.exs`, `host_live/wcvp_test.exs`, `section_live_test.exs`, `taxonomy_form_test.exs`.
