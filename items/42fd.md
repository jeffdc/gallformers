`lib/gallformers/galls/identification.ex` (`Gallformers.Galls.Identification`) is the old ID tool's filter pipeline over the old tables. The ID tool reads `Catalog.identify/1` now (`803b` Tasks 9–10). The old filter was kept on purpose for one use: `mix gallformers.catalog.id_parity` (`lib/mix/tasks/gallformers/catalog/id_parity.ex`, `803b` Task 9). That task runs a sample of real filter sets through both queries on a converted production copy and classes every difference as expected or unexpected (`b5bd` M5's "ID tool and search parity on a sample of real queries").

Expected classes, decided:
- `introduced`: Galls gain their Hosts' introduced range.
- `hosts_whole_range`: every Gall's range is its Hosts' whole WCVP range, except the range-confirmed Galls.

Explained, for review: `everywhere`, `placeholder_waiver`, `range_adjustment`, `outside_hosts_range` (no-inclusions rule, `3272`), `no_inducer`, `not_in_catalog`.

The last recorded run (2026-10-27): 347 filter sets, 0 unexpected (introduced 113, hosts_whole_range 49, outside_hosts_range 9, not_in_catalog 5, placeholder_waiver 0).

**When:** keep both while rehearsals run (`b5bd` M5), since parity is part of the verification suite. Delete them at cutover, once the old tables are no longer there to compare against.
