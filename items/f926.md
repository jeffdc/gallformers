**What:** retire `GallformersWeb.Admin.ReviewLive.ItemRow`, the old question UI. The three pages still on it move onto the new card: the Gallformers notes page's "Needs you", the taxonomy queue and Renames. Then `ItemRow`, the components only it uses, and the second copy of the Trait answer are deleted. This is b230's Task 6 (finding C, "two question UIs on one back end"). It runs after the one answer list (item bceb). It and item a81c (retiring the step and Facts pages) can go in either order. References are as of `65531d59`; go by function names.

**Why (finding C).**
- `ItemRow` is live on `/admin/review/notes` (`review_live/source.ex` about 343), the taxonomy queue (`review_live/taxonomy.ex` about 272) and Renames (`review_live/renames.ex` about 112).
- **The Trait answer is written twice,** and the two send different decision shapes:
  - `ItemRow.term_galls` (item_row.ex about 551-603), with Answer's `galls` state, `pick_galls`/`fill_galls` (answer.ex about 214-227), `effect_for(:galls)` and `choice_decision(:galls)`.
  - `QuestionCard.trait_answers` (question_card.ex about 481-584), with `trait_decision` (about 172-218). This is the one that stays. It sends `%{"categories" => %{gall_ref => [values] | nil}}` for a Trait term, and for a Trait dispute `keep`, `%{"values" => [...]}` or `skip`.
- **The note box is written twice:** `review_notes` (review_components.ex about 2117-2139) and a copy inside `QuestionCard` (about 283-301).
- **Undo differs:** `ItemRow` shows the refusal with its link; `ReviewLive.Review` (review.ex about 181-193, 556-558) shows only the text.
- **Old wording is still live** in `ItemRow`: "Recommended", "To check", "Reject the recommendation" and "No recommendation" (item_row.ex about 425-660). The plain-English pass (6611) replaced these with "Suggested" / "Best guess", and Jeff decided there's no Reject button: unticking in a batch is enough.
- **The hedged sections are listed three times:** `Units` (units.ex about 51), `Review` (review.ex about 49) and `ItemRow` (item_row.ex about 113).

**Jeff's decisions (2026-11-09):**
- **(4) Retire `ItemRow`:** the notes page, the taxonomy queue and Renames move onto the new card.
- **(8) The notes page's "Needs you" tab draws each held note's questions as the Everything view's rows** (`review_question_row` around `QuestionCard`, review.ex about 834-864), so a question looks the same everywhere.

**Build:**
- **First, the retirement entry.** Add `ItemRow` to `test/support/retirements.exs` as the failing test (the file's own example: `%{retire: GallformersWeb.Admin.ReviewLive.ItemRow, replaced_by: GallformersWeb.Admin.ReviewLive.Review, matter: "6611"}`). `Gallformers.Guardrails.Retirements` fails while both modules exist, and nothing else can be committed while an entry is outstanding. Delete `ItemRow` in the same commit, then remove the entry.
- **Move onto `review_question_row` + `QuestionCard`:** the notes page's "Needs you" (decision 8), the taxonomy queue and Renames. Those pages listen for `{ItemRow, {:decided | :undone | :proposal, item}}` today, so they take the card's messages instead.
- **Undo shows its refusal with the link, everywhere.** The refusal text comes from `Import.undo_refusal/1`, with an optional link to the taxon or Gall.
- **The hedged section list is defined once** (fix units.ex about 51, and have `Review` use it).
- **Delete:**
  - `ItemRow`;
  - its components: `review_alias`, `review_ask`, `review_comparison`, `review_decide_bar`, `review_decided`, `review_definitions`, `review_identity`, `review_new_plant`, `review_read_source`, `review_technical`, `review_voices` and `review_segmented`, and their style-guide and catalog entries;
  - Answer's `galls`/`text_value`/`default_value` branch (with `pick_galls`/`fill_galls`, `effect_for(:galls)`, `choice_decision(:galls)`);
  - `QuestionCard`'s inline note box (use `review_notes`).
- With `ItemRow` gone, iNat is searched on every page that shows a name question, so the hint from item bceb mentions iNaturalist everywhere.

**Calls:** `ReviewComponents.review_question_row`, `ReviewLive.QuestionCard`, `ReviewComponents.review_notes`, `Import.undo_decision/2`, `Import.undo_refusal/1`.
