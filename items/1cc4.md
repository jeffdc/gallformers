Main's e2e browser suite (`make e2e`) is broken. #593's lock refresh let the npm `playwright` package float to 1.62.0, whose version string `playwright_ex` 0.5 and `phoenix_test_playwright` 0.13 can't parse, so every `assert_has` raises. Main still has `{:phoenix_test_playwright, "~> 0.12"}` in `mix.exs` and `"playwright": "^1.59.1"` in `assets/package.json` (as of a0434bcf).

**The fix, already on taxogall (2b3dd12d):**
- `phoenix_test_playwright` 0.13 → 0.19 (`mix.exs` `~> 0.19`), which brings `playwright_ex` 0.5 → 0.15 and `phoenix_test` 0.10 → 0.13.1. The lock change is limited to these three.
- npm `playwright` `^1.64.1`, 0.19's minimum.
- The Playwright action timeout is 10 s (`config/test.exs`): on production data a Gall page loads many remote images and map tiles, past the 2 s default.
- `E2ECase.visit/2` waits for the page's LiveView to connect. Playwright's visit returns at the load event, before the LiveView joins, and a `phx-click` sent in that gap is dropped (the section-delete test clicked too early).

On taxogall, `make e2e PROD_DATA_DB=gallformers_taxogall` passed with it (41 + 1 tests). Under 2c8c's rule for production bugs (a small fix branch off main, Jeff pushes and opens the PR), the same change can go to main on its own if e2e on main is needed before the merge.

Lands with the taxogall merge, or as its own fix on main.
