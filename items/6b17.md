Decision 03d0 (Jeff, 2026-11-16): the taxogall API ships as /api/v3 and /api/v2 answers 410 Gone. Traffic analysis behind it: item 3c4f's notes.

- Move the `scope "/api/v2"` block in router.ex to `/api/v3`; the controllers in lib/gallformers_web/controllers/api/ stay as they are.
- Set `API_VERSION` and `GallformersWeb.ApiSpec`'s `info.version` to 3.0.0, so the two numbers agree (today 1.0.5 and 2.1.0). This bump also clears the CI api-version-check on the taxogall PR (Housekeeping 4a47).
- `/api/v2/*` returns 410 Gone with a small JSON body pointing to /api/v3 and /api/docs. Keep it CORS-enabled so browser callers can read the body.
- Add a short "changes from v2" note to the spec description shown at /api/docs: path; places ([] means unknown, may occur anywhere); /galls/:id/sources contents and order; alias types enum and the new meaning of "scientific"; no genus placeholders in /hosts; new taxonomy, alias and trait-value IDs; gall and host IDs unchanged.
- Point lib/mix/tasks/smoke_test.ex at /api/v3 (and fix bug 4745 if it's still open).
- Add the API change to the release-notes list.

Deletes: the /api/v2 routes (replaced by the v3 scope and the 410 catch-all). Calls: the existing API controllers, GallformersWeb.ApiSpec, Gallformers.Version.api_version/0.
