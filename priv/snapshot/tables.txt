# The public database snapshot (.github/workflows/db-snapshot.yml):
# every table in the database, as published (public) or not (private),
# and every schema besides public (private-schema).
#
# The workflow restores the full backup into a scratch database, makes the
# derived tables (priv/snapshot/public_snapshot.sql), drops each
# private-schema (CASCADE, which also drops the audit triggers on public
# tables) and each private table, refuses to publish if any table left is
# not listed public or derived, dumps, and restore-tests the dump.
#
# test/gallformers/public_snapshot_test.exs fails while a table in the
# database is missing here, so a new table cannot leak unnoticed: list it
# in the migration's change.
